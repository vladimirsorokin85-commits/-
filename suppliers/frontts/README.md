Карточка поставщика. Данные сняты с сайта 08.10.2026 (мост GitHub Actions).

| | |
|---|---|
| Сайт | https://front-ts.ru/ |
| Что берём | тактическая одежда и разгрузка, системы подачи боеприпасов, штурмовой инструмент, рюкзаки, тактическая медицина |

| Контакты поставщика | _уточнить у владельца (на сайте в разделах «Контакты»/«Сотрудничество»)_ |

## Что сделано

- `catalog.json` — 64 товара: название, РРЦ, наличие, артикул, бренд, цвета, описание с сайта, фото.
- `groups.json` — разбивка на 7 разделов (одежда, разгрузка/подсумки, системы подачи, медицина, рюкзаки, инструмент, тюнинг).
- `avito.py` + `texts/` — пакет объявлений для Авито (папки по товарам + архивы по разделам).
- `crawl.py`, `parse.py`, `plan.json` — краулер и парсер карточек; запускаются на GitHub Actions
  (`.github/workflows/frontts-fetch.yml`), результат забирается `bash tools/frontts_pull.sh`.

## Как обновить данные

1. `suppliers/frontts/plan.json` → `"mode": "discovery"` (найти новые товары) или `"products"` (перечитать карточки).
2. Коммит + push — workflow запустится сам.
3. `bash tools/frontts_pull.sh` — забрать выгрузку (ветка `frontts-data`).
4. `python3 suppliers/frontts/build_catalog.py` — пересобрать `catalog.json` и `prices/frontts_zakup.csv`.
5. `python3 suppliers/frontts/avito.py` — пересобрать пакет объявлений и архивы.
