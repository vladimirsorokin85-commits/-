# «СВОДКА» — ежедневная передача радио «В ОКОПЕ»

Короткая сводка на 2–3 минуты: что сделано нашими за сутки. Две версии в день —
утренняя и вечерняя. Формат и требования — в `ТЗ.md` (копия ТЗ владельца).

## Что в папке

| Путь | Что это |
|---|---|
| `ТЗ.md` | ТЗ владельца, дословно |
| `studio/gfx.py` | Графика: фон, шапка с щитом и датой, прогресс, футер, тезисы, плашки |
| `studio/scenes.py` | Типы сцен: заставка, порядок выпуска, плитки, стоп-лист, правило, строка направлений, благодарность, CTA, финал |
| `studio/build.py` | Сборка: озвучка → тайминг → подложка → мастер → кадры → mp4 + mp3 + txt |
| `studio/make_script.py` | Факты владельца (markdown) → сценарий выпуска + проверки объёма и стоп-листа |
| `studio/check.py` | Приёмка готового mp4 по ТЗ: разрешение, fps, кодеки, длительность, LUFS, пик, .txt |
| `studio/music_ab.py` | Один выпуск в двух режимах подложки: тихая (ТЗ) и драйв (MUSIC_POLICY) |
| `assets/` | Что прислал владелец: лого-щит и прочее, что движок подхватывает сам |
| `studio/scripts/*.json` | Сценарий выпуска: тексты, сцены, паузы (движок не знает текста) |
| `studio/vo/<slug>/` | Реплики озвучки (в git не кладём) |
| `studio/out/` | Мастер, mp4, mp3, txt (в git не кладём; сдача — отдельным файлом) |

## Как собрать

```bash
cd radio_vokope/svodka/studio
python3 make_script.py ../../facts_2026-11-04_utro.md -o scripts/svodka_2026-11-04_utro.json
python3 build.py scripts/svodka_2026-11-04_utro.json --audio    # только звук + тайминг
python3 build.py scripts/svodka_2026-11-04_utro.json --still 12 40 87   # кадры для проверки
python3 build.py scripts/svodka_2026-11-04_utro.json            # mp4 + mp3 + txt
python3 check.py out/svodka_2026-11-04_utro.mp4                 # приёмка перед сдачей
```

`make_script.py` сам собирает структуру ТЗ (заход → факты → «где наши работают» →
благодарность → CTA → финал), считает слова и ругается, если текст короче 340 слов,
длиннее 430 или в нём есть стоп-лист. Входной формат — `facts_TEMPLATE.md`
рядом с этим README.

Полная сборка 90-секундного выпуска — около 3 минут (≈13 кадров/с).

## Решения, которые надо знать

- **Голос.** Голос из прошлых сессий (voice-28) в новой сессии недоступен.
  Владелец выбрал новый постоянный голос — `voice-29`, низкий мужской, спокойный.
  Темп: 1,12× от исходного синтеза (≈140 слов/мин по ТЗ), без изменения тона.
- **Музыка.** Два режима, переключаются одной строкой в сценарии
  (`"music": {"mode": "quiet" | "drive"}`), сравнение собирает `studio/music_ab.py`:

  | Режим | Музыка в паузах | Речь | Кому |
  |---|---|---|---|
  | `quiet` (по ТЗ) | −31,3 дБ | −17,4 дБ | тихая подложка, верх срезан 4,2 кГц |
  | `drive` (по `MUSIC_POLICY`) | −16,2 дБ | −17,1 дБ | музыка на уровне речи, дакинг 9:1 |

  Готовые фрагменты для прослушивания — `music_ab/quiet.mp3` и `music_ab/drive.mp3`
  (по 26 с с 24-й секунды выпуска). `video_studio/MUSIC_POLICY.md` требует драйв
  ≥120 BPM и музыку −11…−13 LUFS — это прямое противоречие ТЗ, решает владелец.
  `music_check.py`: Arpent = 120 BPM, но «не драйв» (суб 10,9 % < 15 %);
  BeatOne = 162 BPM, «драйв» — если владелец выберет драйв, берём его.
- **Лого-щит.** Положить файл `assets/logo_shield.png` (PNG с прозрачностью) —
  движок сам поставит его в шапку и в финал. Пока файла нет, в кадре нарисованная
  заглушка, вид не ломается.
- **Факты.** Песочница не видит YouTube и новостные сайты. Нужен текст от владельца
  (расшифровка 1–2 выпусков или 5–7 фактов своими словами).

## Порядок боевого выпуска

1. Владелец присылает факты (`facts_YYYY-MM-DD.md`, пометка утро/вечер).
2. Сценарий: заход → 5–7 фактов → «где наши работают» → благодарность →
   куда идти помогать → финал. 350–420 слов, «ты», без пафоса.
3. Реплики озвучиваются по сегментам, `build.py` собирает тайминг и картинку.
4. Проверка: длительность 120–180 с, стоп-лист, читаемость, звук.
5. Сдача: `svodka_YYYY-MM-DD_utro.mp4/.txt/.mp3` (или `_vecher`), первая строка
   `.txt` — «Источник: …».
