# «СВОДКА» — ежедневная передача радио «В ОКОПЕ»

Короткая сводка на 2–3 минуты: что сделано нашими за сутки. Две версии в день —
утренняя и вечерняя. Формат и требования — в `ТЗ.md` (копия ТЗ владельца).

## Что в папке

| Путь | Что это |
|---|---|
| `ТЗ.md` | ТЗ владельца, дословно |
| `studio/gfx.py` | Графика: фон, шапка с щитом и датой, прогресс, футер, тезисы, плашки |
| `studio/scenes.py` | Типы сцен: заставка, порядок выпуска, плитки, стоп-лист, правило, строка направлений, благодарность, CTA, финал |
| `studio/build.py` | Сборка: озвучка → тайминг → подложка → мастер → кадры → mp4 + mp3 + txt |
| `studio/scripts/*.json` | Сценарий выпуска: тексты, сцены, паузы (движок не знает текста) |
| `studio/vo/<slug>/` | Реплики озвучки (в git не кладём) |
| `studio/out/` | Мастер, mp4, mp3, txt (в git не кладём; сдача — отдельным файлом) |

## Как собрать

```bash
cd radio_vokope/svodka/studio
python3 build.py scripts/demo_format.json --audio     # только звук + тайминг (быстро)
python3 build.py scripts/demo_format.json --still 2 40 87   # кадры для проверки вёрстки
python3 build.py scripts/demo_format.json             # полная сборка mp4 + mp3 + txt
```

Полная сборка 90-секундного выпуска — около 3 минут (≈13 кадров/с).

## Что уже проверено на демо-выпуске

| Параметр | ТЗ | Факт |
|---|---|---|
| Разрешение | 1280×720 | 1280×720 |
| Кадры | 25 fps | 25 fps |
| Кодек / пиксели | H.264 yuv420p | H.264 High, yuv420p, level 4.0, `+faststart` |
| Звук | AAC 44,1 кГц, стерео, 128 кбит/с | AAC-LC 44,1 кГц, стерео, 131 кбит/с |
| Громкость | — | −14,5 LUFS, true peak −1,5 dBFS |
| Длительность демо | 120–180 с | 90 с (демо короче — это образец формата, не выпуск) |

Демо: `studio/out/demo_format.mp4`, `.mp3`, `.txt`. В кадре справа сверху стоит
пометка «ДЕМО ФОРМАТА» — в боевых выпусках её нет (`"demo": true` в сценарии).

## Решения, которые надо знать

- **Голос.** Голос из прошлых сессий (voice-28) в новой сессии недоступен.
  Владелец выбрал новый постоянный голос — `voice-29`, низкий мужской, спокойный.
  Темп: 1,12× от исходного синтеза (≈140 слов/мин по ТЗ), без изменения тона.
- **Музыка.** Подложка — `fvi-Arpent.ogg` (120 BPM), обрезка верха 4,2 кГц,
  уровень −24…−20 LUFS под голосом, дакинг под речь. По ТЗ подложка должна быть
  тихой; `video_studio/MUSIC_POLICY.md` требует драйв ≥120 BPM и музыку
  −11…−13 LUFS — это прямое противоречие, нужно решение владельца.
  `music_check.py`: Arpent = 120 BPM, но «не драйв» (суб 10,9 % < 15 %);
  BeatOne = 162 BPM, «драйв» — если владелец выберет драйв, берём его.
- **Лого-щит.** В репозитории логотипа нет: в кадре нарисованный щит с «ВО».
  По ТЗ нужен настоящий — ждём PNG/SVG.
- **Факты.** Песочница не видит YouTube и новостные сайты. Нужен текст от владельца
  (расшифровка 1–2 выпусков или 5–7 фактов своими словами).

## Порядок боевого выпуска

1. Владелец присылает факты (`facts_YYYY-MM-DD.md`, пометка утро/вечер).
2. Сценарий: заход → 5–7 фактов → «где наши работают» → благодарность →
   куда идти помогать → финал. 350–420 слов, «ты», без пафоса.
3. Реплики озвучиваются по сегментам, `build.py` собирает тайминг и картинку.
4. Проверка: длительность 120–180 с, стоп-лист, читаемость, звук.
5. Сдача: `svodka_YYYY-MM-DD_utro.mp4/.txt/.mp3` (или `_vecher`), первая строка
   `.txt` — «Источник: …».
