# Файлы владельца

Сюда кладём присланное — движок подхватывает сам, без правок кода.

## `logo_shield.png`

Настоящий лого-щит: PNG с прозрачным фоном, высота от 512 px (в кадре он мелкий —
в шапке 46 px, в финале 118 px, поэтому чем больше исходник, тем чище).

Как только файл появляется, `gfx.logo_at()` ставит его в шапку и в финал вместо
нарисованной заглушки. Не появился — работает заглушка, вид не ломается.

SVG пока не читаем: в песочнице нет рендерера. Если есть только SVG —
пришлите его, сконвертирую.

## Музыка

Не сюда: подложка берётся из `video_studio/music_downloaded/` (см. `MUSIC_POLICY.md`).
Выбор трека и режима — в сценарии выпуска:

```json
"music": {"track": "fvi-Arpent.ogg", "offset": 12.0, "level": 0.20, "mode": "quiet"}
```
