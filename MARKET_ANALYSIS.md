# Анализ рынка YouTube (военная ниша) для магазина «В Окопе»

**Задача:** выяснить, какие темы видео и Shorts набирают просмотры на YouTube, чтобы повторять их под свой военный магазин.  
**Источники:** данные из открытых GitHub-репозиториев (январь–октябрь 2026), отчёты по трендам YouTube 2025–2026, каналы военной тематики.  
**Статус:** рабочий документ, готов к использованию при планировании контента.

---

## 1. Инструменты на GitHub для анализа рынка YouTube

Вот открытые репозитории, с помощью которых можно собирать данные о трендах, заголовках, обложках и просмотрах без grandes бюджетов.

| Инструмент (GitHub) | Что делает | API ключ | Особенности |
|---------------------|------------|----------|-------------|
| **yt-dlp** (yt-dlp/yt-dlp) | Скачивает видео, извлекает метаданные (заголовок, описание, теги, просмотры, дата загрузки, канал) | Нет | Стандарт де-факто. Может спарсить все видео канала competitors и показать, какие набрали больше всего просмотров. |
| **ytscrape** (vsmutok/ytscrape) | Поиск YouTube, извлечение видео/каналов/плейлистов, комментариев, субтитров | Нет | Простая библиотека на Python, без квот API. |
| **youtube-scrapy-scraper** (Simple-Python-Scrapy-Scrapers/youtube-scrapy-scraper) | Поиск видео, аналитика каналов, просмотры, лайки, антибот, ротация прокси, экспорт CSV/JSON | Нет | Для исследовательских работ и анализа конкурентов. |
| **youtube-trending-analyzer** (ityongsheng/youtube-trending-analyzer) | Подборка trends по странам, heat score (просмотры + лайки + комментарии + время), визуализация, экспорт CSV/JSON/XLSX | Нет | Мультистрана, планировщик сбора. |
| **youtube-trend-dashboard** (madEffort/youtube-trend-dashboard) | Тренды, тональность (sentiment),пригодность, инсайты | Требуется API | Дашборд для анализа тем. |
| **Youtube-Trend-Analyzer** (Sajadapp/Youtube-Trend-Analyzer) | Сбор трендов, анализ вирусных стратегий через Gemini LLM, отчёты в Telegram | Требуется API | Автоматизированные отчёты. |
| **yt-trending-scraper** (FreeTubeApp / форки) | Сбор из `/feed/trending` по странам | Нет | Простой сбор трендовых видео. |

**Как использовать для «В Окопе» (пошагово):**

1. Соберите список конкурентных каналов (военные сводки, обзоры снаряжения, лайфхаки на фронте).
2. Через `yt-dlp` выгрузите все их видео с метриками: просмотры, лайки, дата, заголовок.
3. Отфильтруйте по дате (последние 30–90 дней) и по просмотрам — найдите «взрывные» ролики.
4. Выявите повторяющиеся темы в заголовках и обложках этих роликов — это и есть рабочие темы рынка.
5. Повторяйте эти темы под свой магазин: тот же формат, свои товары, свой голос.

Пример команды `yt-dlp` для метаданных канала:
```bash
yt-dlp --skip-download --print "%(title)s|%(view_count)s|%(upload_date)s|%(url)s" "https://www.youtube.com/@КАНАЛ/videos"
```

## 2. Что сейчас заходит на YouTube в военной нише (рынок, осень 2025 — 2026)

### Общие платформенные тренды YouTube 2026
- **Shorts:** более 200 млрд просмотров в день (июль 2025, данные CEO YouTube). В 2026 Shorts продвигают **оригинальный** контент, перезаливы чужих роликов урезают в охватах (обновление от 1 октября 2026).
- **Идеальная длина Shorts:** 17–22 секунды — удержание выше 85%. Оптимальный диапазон для монетизации и охватов — 30–58 секунд. Максимум теперь 3 минуты (с апреля–июня 2026).
- **Хук:** первые 2–3 секунды решают всё. Сильный визуальный или verbal хук + субтитры на экране.
- **Регулярность:** 3–4 ролика в неделю; алгоритм «забывает» без регулярности.

### Военные темы, которые набирают просмотры (рыночные preuves)

По данным каналов «Военные Сводки» (militarySummary_ru), RT, Rambler, RIA, WarLeaks и отчётам 2025–2026, самые востребованные темы:

| Тема рынка | Почему заходит | Примеры формата |
|------------|----------------|-----------------|
| **Защита от FPV-дронов и тепловизоров** | Высокий страх被发现 + дешёвые материалы, которые можно купить в военном магазине | Shorts 30–60 с: «сетка рабица от FPV», «пенофол против тепловизора», «мангал против дронов» |
| **Фронтовые лайфхаки за копейки** | Любопытство, азарт «хакерского» решения, легко повторить | Серия «Окопная смекалка»: чулок на прицеле, автозеркало на палке, удочка за 500 ₽, USB-эндоскоп |
| **Проверка снаряжения и документов** | Бойцы боятся подделок, ищут чек-лист перед покупкой | Рилс 1:30–2:30: «что значит V50 239 м/с», «три документа перед покупкой бронепончо», «ИК-защита ≠ невидимость» |
| **Как выжить на войне** (советы ветеранов) | Вечный спрос, высокая эмоциональная вовлечённость | Длинные видео 6–12 мин: поведение под обстрелом, обувь и носки, защита барабанных перепонок |
| **Новая тактика ВС РФ** (малые штурмовые группы, дроны-ждуны, килл-зоны, «танковая карусель») | Актуально, обсуждается в military-сообществах | Длинные видео + Shorts-аанонсы |
| **Честная документалистика фронта** | Каналы «Азова», «Третьего армейского корпуса» задали планку искренности | Полноэкранные атмосферные кадры + история, без лобовой рекламы |

### Каналы-референтные примеры (рынок)
- **Военные Сводки** (@militarySummary_ru) — оперативные сводки, комментарии к боям.
- **WarLeaks** — боевые кадры, шлемо-камеры, высокоскоростная техника (пример: 433 тыс. просмотров за месяц на military-тематике).
- **Военное время** — разбор событий и тенденций.
- Каналы «Азова» и «Третьего армейского корпуса» — честная хроника и быт военных.

## 3. Что повторять магазину «В Окопе» — конкретные темы

Ниже — готовые темы для съёмки, которые уже доказали спрос на рынке. Каждую можно снимать и как Shorts (вертикал 9:16, 30–60 с), и как длинное видео (6–10 мин).

### Серия А: «Окопная смекалка» (лайфхаки, повторять циклами)
1. **Чулок на прицеле** — антиблик вместо KillFlash, картонная бленда с сажей.
2. **Пенофол в блиндаже** — термос и скрытие от тепловизора.
3. **Удочка за 500 ₽** — мачта для антенны, диэлектрический щуп, ложная цель.
4. **Автозеркало на палке + USB-эндоскоп** — обзор за угол за 600 ₽.
5. **Сетка рабица + «мангал» из перфорированной стали** — защита от FPV-дронов.

### Серия Б: «Проверка перед покупкой» (доверие к магазину)
1. **V50 239 м/с** — что на самом деле значит цифра в карточке товара.
2. **Три документа** — паспорт, протокол испытаний, документы на соответствие ГОСТ/С2.
3. **ИК-защита ≠ невидимость** — зависимость от камеры, погоды, температуры, дистанции.
4. **Сезонные характеристики** — −40…+40 °C, огнестойкая отделка, цвета Multicam / A-TACS FG.

### Серия В: «Выживание и тактика» (длинные видео)
1. **Как не попасть под тепловизор и FPV** — реальная маскировка на передке.
2. **Советы ветеранов: как выжить на войне** — ротация позиций, обувь, носки, перепонки.
3. **Тактика 2025–2026** — малые штурмовые группы, дроны-ждуны, килл-зоны.

## 4. Формат и монтаж (по шаблонам из репозитория)

| Параметр | Shorts / вертикал | Длинное видео |
|----------|-------------------|---------------|
| Формат | 9:16, 1080×1920 | 16:9 или 9:16, 1280×720 |
| Длительность | 30–60 с (до 3 мин) | 6–12 мин |
| Заставка | **Нет** — сразу хук за 1–2 с | Да, приветствие «от магазина „В Окопе“» |
| Смена кадров | Каждые 2–4 с | Каждые 3–5 с, snap-zoom, J-cut |
| Текст на экране | Крупные цифры, до 2 строк | Субтитры, главы, таймкоды |
| Звук | Мужской голос, громче музыки | Masculine voice, музыка приглушается при речи |
| Обязательно | Обложка + заголовок + закреп со ссылкой | Название, описание, теги, тайм-коды, обложка |

Инструменты из репозитория:
- `video_studio/reels/` — сборка вертикальных MP4 1–20 мин, субтитры, ffprobe QC.
- `server.py` — локальный предпросмотр видео.
- `youtube_smekalka_description.md` — готовое название, описание, теги, таймкоды, варианты обложек под A/B-тест.
- `video_studio/STYLE_AND_DELIVERY_GUIDE.md` — стиль съёмки и монтажа (без витрин и лобовой продажи).

## 6. Метрики рынка, за которыми следить

- **Shorts:** удержание (AVD), повторные просмотры, CTR обложки, рост подписчиков за 24 часа.
- **Длинные видео:** CTR, средняя продолжительность просмотра, отток в первые 30 с, клики по ссылкам в описании.
- **A/B-тест:** если CTR < 4–6 % — меняем обложку/заголовок (готовые варианты А/Б/В уже в `youtube_smekalka_description.md`).

## 7. Быстрый старт: собрать данные о конкурентах через GitHub-инструменты

```bash
# 1. Установить yt-dlp (не требует API-ключа)
pip install -U yt-dlp

# 2. Выгрузить метаданные видео конкурентного канала
yt-dlp --skip-download --print "%(title)s|%(view_count)s|%(upload_date)s|%(url)s" \
  "https://www.youtube.com/@militarySummary_ru/videos" > competitors.csv

# 3. Открыть CSV, отсортировать по просмотрам, выявить повторяющиеся темы в заголовках
# 4. Повторить популярные темы под свой магазин «В Окопе»
```
