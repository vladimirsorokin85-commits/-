# Каталог Димы: снапшот, поиск, наличие

## Файлы

| Файл | Что это |
|---|---|
| `store.py` | доступ к снапшоту: индекс, полные карточки, фото, свежесть данных |
| `remote_fetch.py` | живой фетч каталога и фото (запускается в GitHub Actions или локально) |
| `search.py` | **умный поиск**: синонимы, опечатки, размеры, бюджеты, группировка по моделям |
| `query.py` | привычный CLI: сводка и живой поиск наличия |
| `power.py` | электростанции EcoFlow/Jackery/DJI: прайс, подбор, честный расчёт автономности |
| `synonyms.json` | словарь синонимов и цветов (пиксель = цифра ЕМР; мох = A-Tacs FG Camo) |
| `suppliers.json` | поставщики: Дима, электростанции, Оситинов (пауза) + прайс |
| `requests/photos.json` | **заявка на фото** — что выкачать из каталога |
| `requests/fetch.json` | маркер «обнови каталог» (любое изменение = запуск workflow) |
| `data/`, `photos/` | сами данные снапшота (приходят из ветки `catalog-data`, в git не хранятся) |

## Быстрые примеры

```bash
python3 catalog/query.py                      # сводка: сколько товаров, что в наличии
python3 catalog/query.py ботинки 42           # поиск по словам
python3 -m catalog.search "броник пиксель" --budget 85000 --in-stock
python3 -m catalog.search "подсумок" --color мох --why
python3 -m catalog.power --pick 12h@62W       # что реально тянет 12 часов на 62 Вт
```

## Важное про данные

- Наличие — **только** `stock > 0`. Поле `available` у МойСклад всегда `true`, не использовать.
- `imageURL` в API — мусорная миниатюра 26×19; настоящие фото только через `PUT /getFullImages`
  (может вернуть `[]` — значит фото у поставщика нет).
- API умеет серверный поиск: `GET /products.json?limit=N&search=<слова>`.
- Перед ответом клиенту о наличии — обновить снапшот (см. `docs/WORKFLOW.md`).
