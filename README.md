# Рерайт описаний товаров — магазин «В Окопе»

Рабочая база для подготовки описаний милитари-товаров под **Авито** и **ВКонтакте**.

| Файл | Что внутри |
|---|---|
| [`docs/00-shablon-zapolneniya.md`](docs/00-shablon-zapolneniya.md) | Бланк карточки товара, который присылает заказчик, и формат ответа по умолчанию |
| [`docs/01-pravila-ploshchadok.md`](docs/01-pravila-ploshchadok.md) | Правила Авито, карточек и сообществ ВК, VK Рекламы + закон (150-ФЗ, КоАП 17.12, 546-ФЗ, 289-ФЗ, «Честный знак», 38-ФЗ, экспортный контроль), матрица «где что можно», ограничения доставки |
| [`docs/02-stop-slova-i-zameny.md`](docs/02-stop-slova-i-zameny.md) | Красная и жёлтая зоны лексики, замены слов, запрещённые слова в заголовке, обязательные блоки доверия, самопроверка текста |
| [`docs/03-shablony-i-primery.md`](docs/03-shablony-i-primery.md) | Структуры под Авито / карточку ВК / пост ВК, шаблоны по категориям, примеры «было → стало», чек-лист готовности |
| [`docs/04-rabochiy-rezhim.md`](docs/04-rabochiy-rezhim.md) | Действующий режим работы: только Авито, один товар — один ответ, без цены и доставки; формат выдачи и запретный список |

Ключевой принцип работы: сохраняем точность и факты, убираем триггеры модерации и юридические риски.
Стиль — практичный военный магазин: сухо, по делу, с цифрами, без пафоса и политики.

Действующий режим: **только Авито, работа только с текстом** — цену и доставку в описания не пишем
(«Авито Доставка» не используется, отправка СДЭК и другими ТК по договорённости; за пределы РФ, включая
Беларусь и СНГ, а также в Калининградскую область военное и камуфляж не отправляем).
