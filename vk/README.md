# Посты для ВК

```bash
# пост про одну позицию (цена — розница владельца)
python3 -m vk.post --query "ботинки прабос greyman" --price 24900

# подборка из 3 позиций
python3 -m vk.post --query "перчатки тактические" --limit 3 --template collection

# по коду товара
python3 -m vk.post --code 00895 --price 24900
```

Что получается:

- `vk/out/<slug>.txt` — готовый текст, копируется целиком в ВК;
- `vk/out/<slug>.json` — текст + список фото + метаданные (что и откуда взято);
- в консоль печатается текст и **пути к фото поставщика** — их и грузим в ВК (по порядку).

Правила (полностью — `docs/VK_STYLE.md`): факты только из описания поставщика, фото только
от поставщика, цена только от владельца (иначе «по запросу»), наличие — «на складе у Димы».

Если фото не выкачаны — добавь позицию в `catalog/requests/photos.json` (или укажи `--code`),
запусти workflow «Catalog fetch», выполни `bash tools/catalog_pull.sh` и повтори генерацию.
