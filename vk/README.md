# Посты для ВК

```bash
# пост про одну позицию (цены в постах ВК не указываем)
python3 -m vk.post --query "ботинки прабос greyman"

# подборка из 3 позиций
python3 -m vk.post --query "перчатки тактические" --limit 3 --template collection

# по коду товара
python3 -m vk.post --code 00895
```

Что получается:

- `vk/out/<slug>.txt` — готовый текст, копируется целиком в ВК;
- `vk/out/<slug>.json` — текст + список фото + метаданные (что и откуда взято);
- в консоль печатается текст и **пути к фото поставщика** — их и грузим в ВК (по порядку).

Правила (полностью — `docs/VK_STYLE.md`): факты только из описания поставщика, фото только
от поставщика, **цены в постах не указываем вообще** (правило владельца, 07.10.2026),
наличие — «на складе у Димы».

Флаг `--price 24900` (если нужен) сохраняет вашу розницу только в JSON рядом с постом —
для внутренней записи; в текст поста цена не попадает.

Если фото не выкачаны — добавь позицию в `catalog/requests/photos.json` (или укажи `--code`),
запусти workflow «Catalog fetch», выполни `bash tools/catalog_pull.sh` и повтори генерацию.

## Недельный пакет постов (много постов сразу)

Когда нужно не 1 пост, а комплект на неделю, работает второй скрипт — **`vk/make_pack.py`**.

```bash
# 1) план: 7 дней × 6 постов — vk/posts/plan_2026-10-08_14.json
#    у каждого поста: code, id, headline, hook, (facts — ручные факты), sizes_note
# 2) сборка (тексты + фото поставщика + папки по дням + ZIP)
PYTHONPATH=$PWD/vendor python3 vk/make_pack.py
# результат:
#   vk/posts/pack_2026-10-08/<день>/<пост>/пост.txt + фото 1..3.jpg
#   ВСЕ_ПОСТЫ_ЗА_ДЕНЬ.txt, ВСЕ_ПОСТЫ_НЕДЕЛЯ.txt, README.txt
#   vk/out/V_OKOPE_posts_20261008_week.zip (копия для раздачи — в vk/dist/)
```

Важно: **товар берётся строго по `id`** — коды поставщика не уникальны (62 дубля),
связка по коду даёт не тот товар. Фото подтягиваются из `catalog/photos/` по манифесту
заявки (`catalog/requests/photos.json`).

Правила те же: цены не пишем, факты — из описаний поставщика, фото — только от поставщика.
