## Что это

Простая реклама под соцсети: **18 баннеров на 18 моделей**, каждый — крупное фото товара,
название, 3–4 цифры-козыря, одна рекламная строка и CTA. Плюс 6 сторис для топ-моделей.
Не инфографика, не каталог — реклама, которая читается с телефона за 2–3 секунды.

## Как публиковать

1. Пост 1080×1350 — лента VK/Telegram; квадрат 1080×1080 — VK/Авито, чтобы не обрезалось.
2. Сторис 1080×1920 — истории Telegram/VK и обложки Reels.
3. Подписи — из `00_КОПИРАЙТ\ТЕКСТЫ.md` (хук + козырь + «цена по запросу»).
4. CTA везде: Telegram `@vokope_ru`, телефон `+7 (999) 136-71-42`,
   «Цена по запросу · Доставка по РФ · Самовывоз в Москве».
5. Цены не публикуем; «официальный дилер» не пишем (статус не подтверждён, канон #243).
