# _design — рекламные баннеры «В ОКОПЕ» × НПО «Киловатт»

Бриф: `../00_БРИФ_БАННЕРОВ.md` (18 моделей, форматы 1080×1350 и 1080×1080).
Дизайн-система переиспользует токены/шрифты инфографики: стиль — **рекламный плакат**, не инфографика.

## Состав

| Путь | Что |
|---|---|
| `tokens.css` | копия токенов инфографики (темы `.theme-field` / `.theme-quiet`, шрифты локально, правила «один акцент», без теней/градиентов). |
| `banner.css` | каркас баннера: шапка, айбрау, хук, крупное название, рекламная строка, фото-плашка, 3–4 цифры, футер CTA, отдельная нижняя зона юрстроки. Форматы `.banner--poster` (1080×1350) и `.banner--square` (1080×1080); компоновки `.layout-hero` / `.layout-split` / `.layout-numbers`. |
| `generator.py` | читает `../00_КОПИРАЙТ/banners_data.json`, собирает 36 HTML в `../html/`: `B01_..._1080x1350.html` + `B01_..._1080x1080.html`. Если копирайта нет — берёт `_demo_data.json`. |
| `fonts/` | Sofia Sans Extra Condensed, Oswald, Tektur, Unbounded (OFL, локально). |
| `img/cut/`, `img/product/` | реальные вырезки/фото 18 моделей (из инфографики и каталога), `img/brand/` — логотипы. |
| `shots/` | контрольные рендеры (1080×1350 и 1080×1080) для визуальной проверки. |
| `_qa_check*/` | прогоны детектора renderer (`render_banners.py`): наложения/клипы/выход за кадр. |
| `_demo_data.json` | демо-данные 6 моделей для отладки вёрстки до копирайта. |

## Правила

- **Канон:** без «официального дилера»; футер: «магазин „В ОКОПЕ“ · подбор и поставка»; телефон `+7 (999) 136-71-42`, TG `@vokope_ru`; цены не публикуем («Цена по запросу»).
- Один акцент на макет (field — лайм, quiet — оранжевый), без градиентов/теней/неона/стекла, без стоковых людей.
- Фото — только реальные вырезки, на бумажной плашке; название модели — самое крупное; 3–4 цифры только из claims.
- Юрстрока — отдельная нижняя зона (не «поджата» к футеру).
- Компоновки: `hero` (B01–B07), `split` (B08–B12), `numbers` (B13–B18). Квадрат — перекомпоновка, не растяжка.
- Проверка: `_render/render_banners.py --all --scale 1 --out <temp> --json <temp>/report.json` — 0 FAIL/0 WARN по наложениям.
