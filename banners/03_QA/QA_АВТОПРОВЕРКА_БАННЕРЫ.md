## 5. Методика

- Цифры баннеров сверяются с `infographics\01_ФАКТЫ\claims.json` (единственный источник цифр по факт-политике проекта).
- Запрещённые формулировки — `infographics\01_ФАКТЫ\BANNED.md`; военная риторика — те же правила, что в инфографике.
- Цены: любые ₽/руб. с суммой — блокер; «Цена по запросу» разрешена.
- CTA и юрстрока обязательны в каждом HTML обоих форматов; в данных допускается их отсутствие (их добавляет шаблон).
- **v3 техблок:** `tech` 4–6 строк (label ≤18, value ≤28), `tasks` 2–3 чипа из списка брифа; tech-цифры проверяются
  по числовому корпусу claims.json + `kilowatt\docs\КАНОН_цифры_и_факты.md`, плюс запрет-оверрайды
  (600 Вт «Шторы», 411 кг, 41 позиция, 2/5 км, пожизненная гарантия). Наличие техблока в HTML обязательно.
- Визуальный аудит финальных PNG (читаемость названия/цифр, фото, наложения) выполняется вручную через read_image.
