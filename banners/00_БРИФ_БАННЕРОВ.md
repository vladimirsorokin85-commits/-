## 1. Задача (дословно)

«Нужны тупо рекламные баннеры этих систем. Просто реклама, тупая, которую я буду размещать
в социальных сетях. Каждую из моделей распиши красиво, рекламно, качественно, чтобы со всеми
нюансами и отражалось это всё в дизайне».

То есть **не** объясняющая инфографика, а **рекламный постер на одну модель**: картинка
товара, крупное название, 3–4 цепляющие цифры, короткий рекламный текст и призыв.
Смотрится с телефона за 2–3 секунды, без вчитывания.

## 4. Структура баннера (жёсткий каркас, один взгляд)

1. **Шапка:** лого «В ОКОПЕ» + мелко «НПО «Киловатт» · производитель» + номер/дата.
2. **Хук** (капс, 1 строка, ≤ 40 знаков): например «КУПОЛ НАД МАШИНОЙ».
3. **Название модели** — самое крупное на баннере, плакатный шрифт.
4. **Одна рекламная строка** (≤ 90 знаков): что даёт, кому.
5. **Фото модели** — крупно, на бумажной плашке / с акцентной линией.
6. **3–4 цифры-козыря** (Tektur, крупно): диапазон/дальность/каналы/вес/время/мощность —
   только паспортные и подтверждённые (`infographics\01_ФАКТЫ\claims.json`).
7. **Плашка «для кого»**: авто · мото · объект · периметр · поле · питание (2–3 слова).
8. **Футер:** «Цена по запросу · Доставка по РФ · Самовывоз в Москве»
   + Telegram `@vokope_ru` + `+7 999 136-71-42` крупно.
9. Мелкая юридическая строка: «РЭС. Порядок применения — по законодательству РФ.
   Характеристики — по паспорту изделия.»

**Стиль:** рекламный плакат, не инфографика. Один акцент, крупные цифры, максимум воздуха
и контраста. Тёмная тема `.theme-field` (олива/графит + лайм) для транспорта и носимых;
светлая `.theme-quiet` (тёплая бумага/графит + оранжевый) для стационарных, обнаружения,
питания. Без градиентов, неона, теней, «карточек» и стоковых людей.

## 5. Копирайт: правила

- Тон: коротко, уверенно, по-мужски, без пафоса. Одна мысль на баннер.
- Заголовок/хук — рекламный, но не враньё: без «100% защита», «спасёт жизнь»,
  «дрон не пролетит», «лучший», «единственный», «инновационный», «уникальный»,
  «широкий ассортимент», «комплексный подход», «в современном мире», «является».
- Цены не публикуем: «Цена по запросу».
- Цифры — только из `claims.json` (C0xx) или паспортной выжимки data.js. Нет цифры — нет текста.
- Военная риторика и обещания боевого результата — запрещены. Говорим про защиту
  транспорта/объекта/периметра, обнаружение, подавление, навигацию, питание.
- Каждая модель получает: хук (≤40), название, рекламную строку (≤90), 3–4 цифры с подписями,
  «для кого», и один «козырь-фразу» (1 строка, ≤50) — например «8 каналов против FPV».

   компактнее) и **не должен** ломать рекламную иерархию: название модели остаётся самым
   крупным, фото — самым заметным.
