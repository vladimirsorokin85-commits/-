в макет. Заголовки даны в готовом виде; при переносе строк не менять слова.

## §0. Общие правила для всех постеров

1. **Один постер = один вывод.** Пересказ постера одной фразой — в поле «Вывод».
2. **Заголовок:** ≤ 60 знаков, без длинных тире (—), без кавычек-ёлочек внутри.
   Капслок — да, шрифт `Sofia Sans Cond 800`.
3. **Надзаголовок-метка:** капс, 1 строка, ≤ 32 знака, `Oswald 500`.
4. **Подзаголовок-вывод:** 1–2 строки, ≤ 140 знаков в строке, `Segoe UI`.
5. **Блоки:** 3–7. Метка блока капс, ≤ 26 знаков. Текст блока: 1–3 короткие строки,
   ≤ 90 знаков в строке. Цифры — `Tektur`, крупнее текста.
6. **Цены не публикуем нигде.** Вместо цены: «Цена по запросу» `[C092]`.
7. **CTA строго:** Telegram `@vokope_ru` · `+7 999 136-71-42` ·
   «Доставка по РФ · Самовывоз в Москве» `[C091][C102][C103]`. Других контактов в постерах нет.
8. **Служебная строка на каждой странице:** «НПО „Киловатт“ · производитель» + логотип
   «В ОКОПЕ» + номер постера и дата мелким кеглем.
9. **Запрещено:** «100% защита», «спасёт жизнь», «дрон не пролетел», «гарантированная
   защита», «лучший/единственный/инновационный/уникальный», «комплексный подход»,
   «высокое качество», «работает в любых условиях», военная риторика, политика.
10. **Юр. дисклеймеры** (P05, P06, P10) — из §12, дословно, мелким кеглем но читаемо.
11. Слоган-сквозняк: **«Сначала обнаружь. Потом подави.»** Ставится на P01, P03, P07,
    P09; в остальных не дублируется.
12. Длинные перечисления частот сокращать нельзя: диапазоны пишутся полностью, с «МГц»
    один раз в конце строки. Если не влезает — уменьшить кегль блока, но не выкидывать
    диапазоны.
13. Тон: спокойный мужик, который разбирается. Факт, цифра, вывод. Без восклицаний,
    без «спешите», без «только сегодня».

**Темы (из `kilowatt/design/tokens.css`):**
`.theme-field` (графит-олива + бумажный белый + лайм) — P01, P02, P07, P09;
`.theme-quiet` (тёплый белый + графит + оранжевый) — P04, P06, P08, P10;
