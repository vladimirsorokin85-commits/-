## Что это

Пакет понятной инфографики под новые горизонты продаж продукции НПО «Киловатт»:
**выход в B2B при сохранении розничного сегмента.** 10 постеров + PDF-альбом + галерея.
Один постер = один вывод. Цифры — только паспортные и подтверждённые, цены не публикуются.

## Форматы

- `05_ГОТОВОЕ/png/P01…P10.png` — 1080×1350 (1×), для Telegram/VK/Авито.
- `05_ГОТОВОЕ/png/*@2x.png` — 2160×2700, для печати и ретины.
- `05_ГОТОВОЕ/pdf/Инфографика_Два_горизонта_2026.pdf` — A4-альбом для КП и печати.
- `05_ГОТОВОЕ/gallery/index.html` — галерея всех постеров с подписями.
- `05_ГОТОВОЕ/превью/` — облегчённые JPG для мессенджеров и GitHub.

## Как публиковать (коротко)

1. Постеры P01–P03, P07 — лента Telegram/VK и Авито (соцсети, 4:5).
2. P04–P06, P08, P10 — B2B: в КП, на встрече, в ответ на запрос «пришлите информацию».
3. PDF — целиком в КП и на встрече; 1–2 страницы можно отправлять точечно.
4. Подписи к постам — `00_СТРАТЕГИЯ\05_ТЕКСТЫ_ДЛЯ_ПОДПИСЕЙ.md`.
5. Цены — только в ответ на запрос; в файлах пакета цен нет.
6. Не менять цифры и дисклеймеры вручную: правки — только через `01_ФАКТЫ\claims.json` и повторный рендер.

## Как перерендерить (для разработчика)

1. HTML-постеры: `02_МАКЕТЫ\posters\` (открываются офлайн, шрифты в `02_МАКЕТЫ\_design\fonts`).
2. Рендер PNG: `_render\render_posters.ps1` → `05_ГОТОВОЕ\png\`.
3. PDF: `_render\build_pdf.ps1` → `05_ГОТОВОЕ\pdf\`.
4. Галерея: `_render\gallery.py` → `05_ГОТОВОЕ\gallery\index.html`.
