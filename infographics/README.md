# Инфографика для товаров «В Окопе»

Готовые комплекты слайдов **1080×1350 (4:5)** — VK, Telegram, Avito, Дзен, карточки Ozon/WB.
Единый стиль: графит + жёлтый акцент, тёмное милитари-техно, реальные фото товара (не сток).
Всё лежит в [`out/`](out/), каждый набор — 4 JPG + PDF + ZIP.

## Как пересобрать / поправить

- Слайды нарисованы генератором и лежат в `gen/` (в git не коммитятся — тяжёлые).
- `src/make_final.py <префикс>` — приводит нужные слайды к 1080×1350 (обрезка 4:5, апскейл, unsharp, JPEG q94) и собирает PDF:
  ```bash
  python infographics/src/make_final.py sidewinder_
  python infographics/src/make_final.py slide_
  ```
  Нужен Pillow (`pip install Pillow`).
- `src/cutout.py` — вырезание товара с серого фона, если понадобятся новые кадры на тёмном фоне.
