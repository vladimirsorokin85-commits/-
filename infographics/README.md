# Инфографика для товаров «В Окопе»

Готовые комплекты слайдов **1080×1350 (4:5)** — VK, Telegram, Avito, Дзен, карточки Ozon/WB.
Всё лежит в [`out/`](out/), каждый набор — 4 JPG + PDF + ZIP.

## Логотип

Официальный логотип «В ОКОПЕ · магазин брони» (щит с солдатом-черепом, две звезды).
Файлы в [`assets/`](assets/), прозрачный фон, обрезаны по контуру:

| Файл | Что это |
|---|---|
| `logo_w_full.png` | основной лок-ап: эмблема + «В ОКОПЕ / магазин брони», белый |
| `logo_k_full.png` | тот же в каки (под оливково-песочные макеты) |
| `logo_d_full.png` | тот же в графите (для светлых фонов) |
| `logo_w_emblem.png` / `logo_w_word.png` | эмблема и словесный знак отдельно (белый; есть `_k_`, `_d_`) |
| `logo_preview.png` | как выглядит на тёмном |

В милитари-слайдах (`sw_*`) логотип стоит в футере каждого слайда (эмблема + «В ОКОПЕ / магазин брони»
+ подпись раздела), собирается функцией `logo_lockup()` в `src/compose.py`.

## Как пересобрать / поправить

- Слайды нарисованы генератором и лежат в `gen/` и `gen2/` (в git не коммитятся — тяжёлые).
- `src/finalize.py gen3 sw_` — приводит сгенерированные слайды из `gen3/` к 1080×1350 и собирает PDF (актуальный набор).
- `src/compose.py` — прошлая версия: дорисовка футера и логотипа кодом (оставлена как fallback).
- `src/logo.py` — пересборка логотипа-патча в `assets/`.
- `src/make_final.py <префикс>` — приводит нужные слайды к 1080×1350 (обрезка 4:5, апскейл, unsharp, JPEG q94) и собирает PDF:
  ```bash
  python infographics/src/make_final.py sidewinder_
  python infographics/src/make_final.py slide_
  ```
  Нужен Pillow (`pip install Pillow`).
- `src/cutout.py` — вырезание товара с серого фона, если понадобятся новые кадры на тёмном фоне.
