## 2. Постоянные правила оформления, звука и подачи (ОБЯЗАТЕЛЬНО ДЛЯ ВСЕХ НОВЫХ РОЛИКОВ)
1. **Без таймкодов в описании вертикальных видео (`9:16` Shorts / VK Клипы / Reels)**:
   - В текстовых описаниях для вертикальных роликов **НЕ добавлять** блок `⏱ Таймкоды` / строки `00:00 — ...` (оставлять чистое структурированное описание, теги через запятую для YouTube Studio и текст закреплённого комментария со всеми 3 официальными ссылками).
2. **Приоритет разборчивости диктора `voice-05` над музыкой (Broadcast Ducking Standard)**:
   - Музыка — **строго нарезанные реальные студийные `.mp3` треки Drum & Bass (`174–175 BPM`, `320 kbps`, без вокала)**; внутренний синтезированный муз-движок **строго запрещён**.
   - Чтобы мощный дроп Drum & Bass **ни в одном моменте не перекрикивал диктора**, использовать **удерживающую огибающую сайдчейна по всей фразе** `[vo_start - 0.10s .. vo_end + 0.14s]` (без «выпрыгивания» ударных в микропаузах между словами), уровень музыки под голосом **`~0.18–0.19`** при уровне голоса **`1.02`**, плюс мягкий вырез **`-3.0 dB` на `2200 Гц`** в музыкальной дорожке под речевой диапазон и выход в чистый музыкальный хвост (`~2.2–2.6 с`) в финале до `-14.0 LUFS`.
3. **Строгие запреты по контенту**:
   - **НИКОГДА** не указывать рублёвые цены (`0 ₽`) в кадре, озвучке, описании, на обложках или в студии — делать акцент на реальных ТТХ, заводской комплектации и поставке **оптом и в розницу, с НДС и без НДС**.
   - **НИКОГДА** не указывать личные контакты менеджеров (`@VES_nn`) и служебные ссылки каталога (`moysklad.shop`, слова «онлайн-каталог»).
   - **ВСЕГДА** использовать реальные студийные фото товаров, фирменный логотип **`В ОКОПЕ — магазин брони` (`GOYDA`)** и выбранный голос **`VC-05` (`voice-05`)**.
4. **Обязательная генерация обложек (Thumbnails / Covers) для ВСЕХ горизонтальных и вертикальных видео**:
   - Для **каждого** выпускаемого ролика (как горизонтального `16:9`, так и вертикального `9:16`) в обязательном порядке генерировать и прикладывать готовые высококонтрастные обложки в `New_Video_bilder/output/covers/`:
     - **Горизонтальная обложка `16:9` (`1920×1080`, JPEG `< 2 МБ`)** для YouTube, VK Видео, RuTube и встраиваний — с чистой безопасной зоной в правом нижнем углу (`260×110 px` под плашку хронометража плеера).
     - **Вертикальная обложка `9:16` (`1080×1920`, JPEG `< 2 МБ`)** для YouTube Shorts, VK Клипов, Reels и Telegram — с размещением заголовка, товара и ключевых ТТХ в центральной безопасной зоне (`y = 210 .. 1680`), чтобы ничего не перекрывалось интерфейсом Shorts/Клипов и не обрезалось в сетке профиля.
   - Обложки подключать атрибутом `poster` и кнопками скачивания в `New_Video_bilder/studio/index.html`, а также отдавать прямыми ссылками вместе с видео и текстовым пакетом.


## 3. СТРОГОЕ ПРАВИЛО ПРОВЕРКИ АВТОРСКИХ ПРАВ И CONTENT ID НА МУЗЫКУ (ОБЯЗАТЕЛЬНО!)
- **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО** использовать коммерческие треки лейблов (Monstercat, RAM Records, Subtitles, Hospital Records, Warner, NCS с обязательной атрибуцией и т.д. — в том числе *Feint — Time Bomb*, *Pendulum — Witchcraft*, *Calyx & TeeBee — The Quest* и любые треки из чужих пользовательских подборок без лицензии автора), а также треки с сервисов, регистрирующих аудио в HAAWK / Identifyy / AdRev / YouTube Content ID / Meta Rights Manager / VK ACRCloud.
- **РАЗРЕШЕНЫ ТОЛЬКО треки под лицензией `CC0 1.0 Universal (Public Domain Dedication)`** (`https://creativecommons.org/publicdomain/zero/1.0/`), по которым:
  1. Проверен первоисточник и явный отказ автора от исключительных прав (`CC0 1.0` — разрешено любое коммерческое и рекламное использование по всему миру без отчислений и без обязательного указания авторства);
  2. Выполнена проверка через поиск на отсутствие жалоб YouTube Content ID / HAAWK / Identifyy;
  3. Выполнена нейросетевая проверка `Silero VAD` (`0.00%` вокала — чистый инструментальный `174–175 BPM` Drum & Bass / Tech-DnB / Neurofunk, чтобы ничто не перебивало диктора `voice-05`);
  4. Файл, SHA-256 хеш, автор и ссылка на `CC0 1.0` источник занесены в реестр `New_Video_bilder/assets/audio/music_mp3/licenses_manifest.json` + `LICENSES.md` и проходят автопроверку **`npm run verify:music`** (`python3 src/verify_music_rights.py` == `exit 0`).
