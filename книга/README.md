# Книга

Рабочая папка литературного цикла по вселенной «Библия вселенной». Здесь хранится текст канона и машиночитаемая база данных, из которой потом можно собирать сюжеты, хронологии, карточки персонажей и проверять тексты на противоречия.

## Состав

| Путь | Что это |
| --- | --- |
| `БИБЛИЯ_ВСЕЛЕННОЙ_Том_I_v1.0.md` | Исходный текст канона. Том I «Государство и правосудие», версия 1.0 |
| `данные/canon.json` | **Источник правды.** Все сущности, разделы, утверждения, числа, термины и открытые вопросы в структурированном виде |
| `вселенная.db` | SQLite-база, собранная из `canon.json`. Только для чтения и запросов — править её вручную не нужно |
| `инструменты/build_db.py` | Сборка базы, проверка JSON и вывод SQL-схемы |
| `схема_базы_данных.md` | Описание таблиц, полей и связей |

## Быстрый старт

```bash
# проверить JSON на ошибки и ссылочную целостность
python3 книга/инструменты/build_db.py --check

# пересобрать базу после правок canon.json
python3 книга/инструменты/build_db.py

# посмотреть SQL-схему
python3 книга/инструменты/build_db.py --schema

# открыть базу
sqlite3 книга/вселенная.db
```

Сторонние зависимости не нужны: только Python 3 и встроенный `sqlite3`.

## Что уже в базе

- 18 сущностей: государство, президент В. В., СБ, полиция, суды, лептопы, трудовые учреждения и др.
- 29 разделов канона, включая подразделы 3.1, 3.2, 7.1, 7.2, 14.1–14.3, 15.1, 17.1.
- 183 утверждения с привязкой к разделу и сущности и с меткой достоверности.
- 15 числовых параметров: нормативы реагирования, лимиты баллов, проценты удержаний, доля оправданий.
- 4 категории правонарушений, 7 видов наказаний, 8 терминов, 15 открытых вопросов.

## Статусы достоверности

Поле `canon` есть у сущностей и утверждений:

| Значение | Смысл |
| --- | --- |
| `canon` | Утверждённый рабочий канон |
| `partly_undefined` | Зафиксировано частично, детали открыты |
| `undefined` | Прямо названо неопределённым в документе |
| `rumor` | Неподтверждённые слухи внутри вселенной (раздел 17.1) |

Слухи намеренно не смешиваются с каноном: при написании текстов их можно использовать как точку зрения персонажей, но не как факт мира.

## Примеры запросов

```sql
-- всё, что известно про Службу безопасности
SELECT id, statement FROM facts WHERE entity_id = 'security_service' ORDER BY id;

-- все числа одним списком
SELECT name, value, unit, note FROM parameters ORDER BY id;

-- правила про баллы
SELECT f.statement FROM facts f JOIN sections s ON s.id = f.section_id
WHERE s.id = '3' OR s.parent_id = '3' ORDER BY f.sort_order;

-- что ещё не решено
SELECT id, question, origin FROM open_questions WHERE status = 'open' ORDER BY id;

-- только слухи
SELECT statement FROM facts WHERE canon = 'rumor';

-- поиск по словам
SELECT id, substr(statement, 1, 80) FROM facts WHERE statement LIKE '%лептоп%';
```

## Как дополнять

1. Правки вносим в `данные/canon.json`.
2. Новое утверждение получает следующий свободный `id` вида `F-184`, ссылку на `section`, при наличии — на `entity`, и `kind` (`rule`, `procedure`, `right`, `restriction`, `sanction`, `norm`, `description`, `example`, `principle`, `statistic`, `rumor`).
3. Если появляется новый раздел — сначала запись в `sections`, затем утверждения.
4. Если утверждение меняет ранее принятое — старое не удаляем сразу: меняем его `canon` на `undefined` и добавляем новое, а в `versions` пишем, что изменилось. Так сохраняется история решений.
5. Запускаем `build_db.py` — он проверит ссылки и пересоберёт базу.
6. Текст в `БИБЛИЯ_ВСЕЛЕННОЙ_Том_I_v1.0.md` обновляем под новую версию (например, `v1.1`), чтобы документ и база не расходились.

## Открытые вопросы

Раздел 20 документа перенесён в таблицу `open_questions` (Q-01…Q-10). Туда же добавлены редакционные вопросы, возникшие при разборе текста (Q-11…Q-15), — их стоит решить до того, как соответствующие места попадут в сюжет:

- восстанавливается ли лимит до 20 баллов, если он был повышен или снижен;
- бессрочен ли повышенный лимит;
- как соотносятся автоматическая квалификация и решение суда;
- кто входит в комиссию из слухов о воспоминаниях;
- есть ли сроки погашения у средних нарушений.

## Замеченные места, требующие решения

При переносе текста в базу обнаружены формулировки, которые при работе над сюжетом дадут противоречия. Они не исправлены — канон сохраняется дословно:

1. **Раздел 7:** после уплаты штрафа «обычно восстанавливается стандартный лимит в 20 баллов» — но в 3.2 лимит может быть 10 или 22. Нужно решить, сбрасывается ли лимит к 20 всегда.
2. **Раздел 9:** для безработного 50% заработка идёт на штраф, а для трудоустроенного дополнительные работы оплачиваются полностью в счёт долга. Не описано, что происходит с основным доходом уже работающего должника.
3. **Раздел 17.1:** слухи о процедурах официально не подтверждены, но вернувшиеся люди описаны как реальный факт. Стоит зафиксировать, что именно считается каноном.
4. **Раздел 18:** «Поля» и «Шахты» упомянуты как разные формы труда, но различие не описано — пока это только лексика.
5. **Раздел 3:** не сказано, сколько баллов списывается за нарушение каждой категории, — без этой таблицы балльную механику нельзя использовать в сюжете.
