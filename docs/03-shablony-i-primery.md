# Шаблоны и примеры готовых текстов

**Рабочий формат — только Авито** (см. `docs/04-rabochiy-rezhim.md`):

- **А** — объявление на Авито: **заголовок не трогаем (он ваш)**, переписываем только тело —
  800–1500 символов, без цены, без доставки, без контактов и ссылок, без эмодзи и КАПСА.
- **Б** и **В** — шаблоны под карточку товара ВК и пост ВК. Держим как запасной вариант, если понадобится
  расширить площадки; в текущей работе не используем.

Общее правило для всех форматов: **цену и способы отправки в текст не пишем никогда**. Цену ставит владелец
магазина, условия доставки согласуются в переписке. Мы не работаем через «Авито Доставку» — только СДЭК
и другие ТК по договорённости, а за пределы РФ (включая Беларусь и весь СНГ) и в Калининградскую область
форму, камуфляж, бронезащиту, шлемы и оптику не отправляем.

Стилистика: спокойно, по делу, с цифрами. Мы знаем своё снаряжение и не играем в войнушку.

## 1. Универсальная структура

### Авито
```
[Заголовок — ваш, публикуется без изменений]

Что это и для чего — 1–2 строки (это видно в поисковой выдаче).

Характеристики:
— материал / ткань / сталь;
— размеры, рост, вес;
— класс защиты или рабочая характеристика (по документу);
— совместимость, крепление, интерфейс;
— особенности конструкции.

Комплектация:
— поштучно, что входит;
— что в комплект не входит.

Состояние и происхождение:
— новое, из наличия, производитель, страна;
— документы: только если они реально есть — тип, номер и срок действия (по запросу в чате).
  Если документов нет — блок не пишем вообще и ничего не обещаем;

Честно о нюансах: 1 строка.

Финальная строка:
— нейтральный призыв написать в сообщения (подбор размера, дополнительные фото, документы);
— без цены, без города, без способа доставки, без упоминания «Авито Доставки».
```

### Карточка ВК
```
[Название: тип + бренд/модель + параметр, ≤120 симв., без эмодзи и КАПСА]

Описание до 4000 символов, первые ~220 — самое важное.
Абзац 1: назначение и ключевая характеристика.
Абзац 2: материалы, размеры, вес, совместимость.
Абзац 3: комплектация.
Абзац 4: производитель, документы, условия обмена и возврата.
Без цены (есть поле), без ссылок, без контактов, без эмодзи, без спецсимволов.
```

### Пост ВК
```
[1 строка-крючок: что за позиция и кому нужна]

Эмодзи-маркер Характеристики:
— пункт;
— пункт.

Эмодзи-маркер Комплектация:
— пункт;
— пункт.

Цена: X ₽. Наличие: N шт. / под заказ X дней.

Практическое замечание от нас (подгонка, совместимость, типичная ошибка).

Призыв: пишите в личные сообщения группы — подскажем по размеру и доставке.
```

## 2. Шаблоны по категориям

### 2.1. Бронезащита (плитоносцы, бронежилеты, плиты, противоосколочные модули)
- Опорные факты: класс защиты по ГОСТ Р 50744-95 (Бр1, Бр2…), тип пакета (СВМПЭ/UHMWPE, арамид),
  материал чехла (Cordura 1000D), размер и рост, вес, совместимость с плитами (Гранит 2/3, SAPI S–XL),
  наличие MOLLE, клапанов, плечевой системы.
- Не пишем: «боевой», «штурмовой для войны», «пуленепробиваемый», «спасёт жизнь», «стоял на вооружении».
- Доставка в тексте не упоминается. По факту такие позиции уходят только ТК по договорённости и только
  по РФ: за рубеж и в Калининградскую область не отправляем.

### 2.2. Шлемы и защита головы
- Опорные факты: класс защиты, материал, размер/обхват, вес, тип рельсов и креплений (Ops-Core-совместимые),
  наличие подкладки, регулировки, совместимость с наушниками и очками.
- Не пишем: «боевая каска ВС РФ», «держит выстрел», «армейский образец».

### 2.3. Разгрузочные системы, пояса, подсумки
- Опорные факты: тип платформы (РПС, пояс с внутренним ремнём, плечевая система), ячейки MOLLE/PALS,
  размеры и регулировка, материал, фурнитура (2М, ITW Nexus), вес пустой, вместимость.
- Не пишем: «под АК», «под магазины 5,45», «боевая разгрузка».

### 2.4. Одежда и обувь (камуфляж, куртки, брюки, берцы)
- Опорные факты: состав ткани и плотность, расцветка (точное название), размерная сетка и соответствие
  («идёт в размер», «маломерит»), рост, крой, карманы, усиления, фурнитура, вентиляция, влагозащита,
  возможность установки наколенников, вес. Для обуви: материал верха и подошвы, полнота, стелька,
  высота берца, температурный диапазон, шнуровка/фурнитура.
- Не пишем: «уставная форма ВС РФ», «с погонами», «форма МВД/ФСБ», шевроны принадлежности.
- Обязательный вопрос: маркировка «Честный знак» (одежда, обувь, головные уборы, перчатки, ремни — да;
  с 01.03.2026 ещё и защитные головные уборы и спецодежда).

### 2.5. Рюкзаки и сумки
- Опорные факты: объём в литрах, габариты, вес пустого, материал и плотность, количество отделений,
  MOLLE, совместимость с гидратором (объём), лямки и пояс, вентиляция спины, влагозащита, цвет.

### 2.6. Электроника (рации, наушники, фонари, батареи)
- Опорные факты: диапазон и мощность, количество каналов, защита IP, автономность, ёмкость и тип АКБ,
  время заряда, вес, интерфейс (NATO U-174/U, тип разъёма), совместимость, комплектация, страна.
- Не пишем: «шифрование», «криптостойкий канал», «частоты силовых структур», «подавление».
- Для наушников: «средство защиты слуха и связи», порог срабатывания, шумоподавление в дБ, режимы.

### 2.7. Оптика (монокуляры, ПНВ, тепловизоры, коллиматоры)
- Опорные факты: кратность, диаметр объектива, разрешение матрицы, частота обновления, дальность
  обнаружения, питание, защита IP, вес, крепление (кронштейн/адаптер), назначение — **наблюдение,
  ориентирование, охота**.
- Не пишем: «прицел на оружие», «боевая кратность», «для стрельбы по людям», «крепится на ствол».
- С 04.07.2026 законодательный запрет продажи прицелов НВ для гражданского и служебного оружия снят,
  но модерация площадок всё равно режет прямую связку с оружием.

### 2.8. Ножи и инструменты
- Опорные факты: тип (хозяйственно-бытовой, туристический, разделочный), длина клинка, толщина обуха,
  сталь и твёрдость HRC, материал рукояти, тип замка (для складных — не автоматический!), общая длина,
  вес, наличие чехла/ножен.
- **Обязательно**: фраза «изделие хозяйственно-бытовое, не относится к холодному оружию» + фото сертификата
  или информационного листка в объявлении (Авито это прямо разрешает и рекомендует).
- Не пишем: «боевой нож», «для самообороны», «холодное оружие», «автоматический», «бабочка», «метательный».

### 2.9. Полевый быт и мелочи (спальники, коврики, посуда, термосы, патчи, ремни, перчатки)
- Опорные факты: температура комфорта, вес, габариты в упаковке, материал, объём, размер, крепление
  (велкро, MOLLE), страна производства.
- Патчи: без ведомственной символики, госнаград, нацистской и экстремистской атрибутики, без позывных
  конкретных подразделений.

## 4. Чек-лист готовности позиции (на каждую карточку)

- [ ] Категория выбрана корректно, товар реально в наличии.
- [ ] Заголовок ≤ 50 символов (Авито), без триггерных слов, цены и контактов.
- [ ] Первые 200 символов (Авито) и 220 символов (ВК) содержат суть.
- [ ] Нет слов из красной зоны (`docs/02-stop-slova-i-zameny.md`).
- [ ] Нет контактов, ссылок и мессенджеров в объявлениях Авито и в карточках ВК.
- [ ] Нет эмодзи и КАПСА в карточках ВК; в заголовке Авито — тоже.
- [ ] Все цифры взяты из исходника, ничего не придумано. Класс защиты — строго по документу.
- [ ] Комплектация поштучно, указано чего нет в комплекте.
- [ ] Есть хотя бы один честный нюанс.
- [ ] Блок про документы — только при их реальном наличии (по умолчанию у магазина документов нет,
      значит блока нет). Реестровая ссылка по 546-ФЗ размещается в профиле или на сайте, не в тексте.
- [ ] Нет ни цены, ни блока про доставку, ни города, ни упоминания «Авито Доставки».
- [ ] Маркировка «Честный знак» проверена для одежды, обуви, головных уборов, перчаток, ремней, СИЗ.
- [ ] Текст уникален: не копия наших же объявлений и не копипаст поставщика.
- [ ] Фото свои, без водяных знаков, контактов и чужих логотипов; для ножей — снимок сертификата.
- [ ] Версия только под Авито (ВК — по отдельному запросу); текст не дублирует наши же объявления.
