# Примеры результатов (собрано 07.10.2026 на живом каталоге)

Все примеры сделаны на реальных данных поставщика — фото и факты оттуда, ничего не выдумано.

| Файл | Что показывает |
|---|---|
| `voevoda.jpg` | карточка «ВОЕВОДА 14/23» (6 фото поставщика, особенности/характеристики из описания, цена «по запросу») |
| `order_example.png` | бланк подбора из 3 позиций: ботинки + подсумок ×2 + аптечка, итог «уточняется» |
| `ботинки-prabos-greyman-*.txt` | пост ВК про ботинки (цена-пример 24 900) |
| `аптечка-тактическая-rhino-*.txt` | пост ВК про аптечку (цена-пример 7 900) |
| `комплекс-бронезащиты-воевода-*.txt` | пост ВК без цены → «Цена: по запросу» |
| `подсумок-мох.txt` | подборка из 3 подсумков (шаблон `collection`) |
| `*.json` | служебные: какие товары и фото вошли в пост, источник снапшота |

Цены в примерах постов — **условные**, чтобы показать вид текста. Реальные цены назначает
только владелец (правило из `docs/KNOWLEDGE_BASE.md`).
