# Посты для ВК «В ОКОПЕ» — правила и шаблоны

## Железные правила постов

1. **Факты — из описания поставщика; мало данных — ищем в проверенных открытых
   источниках** (сайт производителя, официальные дистрибьюторы, бренд). Ни одной
   выдуманной характеристики: чего не нашли — в пост не идём.
2. **Фото только от поставщика** (каталог Димы / поставщик электростанций).
   Никаких картинок из интернета и маркетплейсов — никогда.
3. **ЦЕНЫ В ПОСТАХ НЕ УКАЗЫВАЕМ ВООБЩЕ** (правило владельца, 07.10.2026). Ни розницы,
   ни «от ...», ни «цена в личку». Флаг `--price` в генераторе только сохраняет вашу
   розницу в JSON рядом с постом — для внутренней записи; в текст он не попадает.
4. **Наличие** — «на складе у Димы» (для электростанций — «подтверждаем наличие у поставщика»).
   Нет позиции — не пишем пост про неё вовсе.
4.00. **Цены и акции — только с одобрения владельца** (07.10.2026): цену на каждую
   публикуемую позицию спрашиваем заранее; любую акцию/скидку сначала проговариваем
   в чате и только потом ставим в пост.

4.0. **Доставка и оплата (правило владельца, 07.10.2026):** отправляем СДЭК,
   **оплата при получении по тарифу СДЭК**. Эту формулировку ставим в конец поста —
   это сильный аргумент для покупателя («оплата при получении», не предоплата).
4.1. **Количество остатков в постах не пишем** (правило владельца, 07.10.2026):
   ни «осталось 3 шт», ни «9 штук на складе», ни «уходят быстро». Сколько есть —
   это внутренняя информация для личных сообщений, а не для поста.
4.2. **Внутренние формулировки в публикуемом тексте запрещены** (правило владельца,
   07.10.2026, после случая с «есть на складе у Димы»): слова «у Димы», «поставщик»,
   «на складе» в пост не попадают НИКОГДА — они только для внутренних отчётов владельцу.
   В посте — нейтрально: «В наличии.» или «В наличии: размеры M–3XL.»
   Генератор проверяет это автоматически (`check_public_text` в `vk/make_pack.py`).
5. **Никаких обещаний**, которых нет в описании (например бронекласс, если он не указан).
6. Одна позиция = один пост; подборка — не больше 5 строк, иначе не читают.
7. **Пост продаёт и объясняет профессионально:** зачем вещь, какую задачу решает,
   чем эта модель отличается — а не «есть в наличии, пишите».

## Каркас поста (template `product`)

```
🪖 <Название по-человечески: модель + цвет>

<Подзаголовок из описания: что это и для кого>

Что важно:
▪️ <факт 1 из «Особенности»/«Характеристики»>
▪️ <факт 2>
▪️ <факт 3>

В наличии: 42 — 1 шт · 44 — 1 шт

Доставка по РФ. Пишите в личные сообщения — подберём под вашу задачу.

#вокопе #магазинброни #экипировка #ботинки #обувь
```

Подборка (`--template collection`):

```
🪖 Подборка из наличия (проверено у поставщика)

1. <модель>
   в наличии: 42 — 1 шт · 44 — 1 шт
...
Всё со склада у Димы. Пишите в личку — забронирую и отправим СДЭК.
#вокопе ...
```

Остатки (`--template stock`) — короткий список «что есть», без цен, для «живых» сторис/постов.
Цен нет ни в одном шаблоне — это железно.

## Чего избегаем

- Полотен текста: больше ~900 знаков не читают.
- Канцелярита и рекламных штампов («уникальное предложение», «не упустите шанс»).
- Эмодзи-мусора: 1–2 уместных, остальное — звёздочки и тире.
- Обещаний сроков доставки — только «СДЭК», детали в личке.

## Хештеги

Автоматически: `#вокопе #магазинброни #экипировка #тактика` + категорийные
(обувь, бронежилет, связь, медицина…). Максимум 10.
