# Решения по формату текстов (фиксируем один раз, применяем ко всем товарам)

Принято 03.10.2026 по итогам разбора объявления на активные наушники ZTAC Comtac II.

| Вопрос | Решение | Что это значит в тексте |
|---|---|---|
| Заголовок | **Заголовки пишет владелец магазина, я их не правлю** (решение от 03.10.2026). Площадка — Авито: если объявление снимут, его просто заменят | Беру заголовок как есть, работаю только с телом. Могу один раз пометить риск в заголовке, но не переделываю |
| Бренд и чужие товарные знаки в теле | В заголовке бренды — как у вас (в т.ч. «Ztac Peltor Comtac II»). В теле оригинал чужим брендом не называем и за него не выдаём | В описании нейтральная оговорка: «изделие конструктивно повторяет Comtac II и не является продукцией 3M Peltor». Совместимость: «совместимо со шлемами типа Ops-Core» |
| Категория объявления | Оставляем ту, что реально работает у магазина (например «Коллекционирование» для электроники и снаряжения) | Категорию в текстах не упоминаем (правила и так запрещают писать название категории в описании). Пометку о риске несоответствия категории даю только один раз, дальше не повторяю |
| Документы (сертификаты, декларации, отказные письма) | Документов на позиции нет | **Блок про документы не пишем вообще.** Никаких «декларация действует», «сертификат по запросу», «класс защиты по ГОСТ» без реального документа. Классы защиты и ТТХ указываем только как данные производителя |
| Цена | Ставит владелец магазина | В тексте цены нет никогда, включая оптовые сетки «от N шт.» |
| Доставка | «Авито Доставку» не используем, только СДЭК и другие ТК по договорённости | В тексте нет ни способа отправки, ни города, ни «самовывоза». За рубеж (включая Беларусь и СНГ) и в Калининградскую область военное и камуфляж не отправляем — это правило для переписки, не для объявления |
| Контакты и ссылки | Запрещены правилами Авито | Телефон, e-mail, мессенджеры, сайты, ВК, QR — никогда. Финальная строка: «пишите в сообщения» |
| Объём | Заголовок ≤ 50 символов, описание 800–1500 (до 2000 для дорогих комплектов) | Первые 200 символов описания — суть, их видно в поисковой выдаче |
| Тон | Практичный военный магазин | Без пафоса, без «!», без «элитных подразделений», «условий боя», «бойца», «выстрелов и разрывов». Сухо, по делу, с цифрами |
| Честность цифр | Только из присланного исходника | Недостающее — короткий вопрос, а не догадка. Классы защиты, дБ, автономность, тип батарей — только по вашей инструкции или карточке поставки |

## Следствие для структуры описания

Финальная структура объявления Авито:

```
[Заголовок — ваш, без изменений]

Что это и для чего — 1–2 строки (видно в выдаче).

Характеристики:
— ...

Комплектация:
— ... (и чего в комплекте нет)

Производитель и страна. Оговорка про реплику, если нужна.
Состояние.

О нюансах: одна честная строка.

Финал: «Пишите в сообщения — подскажу по [размер/совместимость/подбор], пришлю дополнительные фото.»
```

Блоков «Цена», «Доставка», «Документы», «Контакты» в тексте нет.


## Поправка от 04.10.2026: продающий стиль, без лишней перестраховки

Владелец решил: тексты — коммерческие, красивые, продающие. Названия расцветок и материалов
(A-TACS FG, Multicam, Kevlar и т.п.) не вырезаем. Из исходника сохраняем всё полезное и усиливаем
подачу, а не сокращаем её. Вырезаем только то, что реально снимает объявление или создаёт риск:
контакты, цены в тексте, красную зону (оружие, боеприпасы, боевые действия, силовики), медицинские
гарантии, поисковый спам, чужие товары в описании. Вопросы владельцу задаём только когда данных
реально не хватает для сделки, а не по каждому пункту.
