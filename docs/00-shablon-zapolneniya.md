# Карточка товара — бланк для заполнения

Копируй и присылай в таком виде — на выходе получишь готовые версии под Авито и ВК.
Что не знаешь — оставь пустым, я не буду придумывать цифры сам.

```
1. Товар (тип, модель, бренд):
2. Исходное описание (как есть, можно копипастом от поставщика):
3. Цена:
4. Наличие (сколько штук / под заказ, срок):
5. Характеристики (материал, размеры, рост, вес, цвет, класс защиты, совместимость, питание и т.п.):
6. Комплектация (что входит поштучно; чего НЕТ в комплекте):
7. Состояние (новое / б/у, следы эксплуатации):
8. Производитель и страна:
9. Документы (сертификат / декларация / информационный листок: тип, номер, срок; класс защиты по ГОСТ):
10. Маркировка «Честный знак» (есть / нет / не требуется):
11. Город самовывоза:
12. Как реально отправляем (самовывоз / ТК / Авито Доставка / Почта):
13. Условия обмена и возврата (если отличаются от стандартных):
14. Известные нюансы и честные минусы товара:
15. Фото (сколько, есть ли снимок сертификата, есть ли на фото знаки различия / чужие логотипы / вода-знаки):
16. Куда публикуем: [ ] Авито  [ ] карточка ВК  [ ] пост ВК  [ ] всё сразу
```

## Формат ответа по умолчанию

1. **Авито** — заголовок (≤50 симв.) + описание 800–1500 симв., без контактов и ссылок, без эмодзи.
2. **Карточка ВК** — название (≤120 симв.) + описание до 4000, без цены в тексте, без эмодзи, КАПСА
   и спецсимволов.
3. **Пост ВК** — витринный вариант с эмодзи-маркерами, ценой и призывом написать в ЛС группы.
4. Пометка по рискам: что в этой позиции может не пройти модерацию и чем заменить.
5. Счётчик символов для заголовков и описаний (чтобы не резало площадка).
