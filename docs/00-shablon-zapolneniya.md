# Карточка товара — бланк для заполнения

Режим (см. `docs/04-rabochiy-rezhim.md`): **только Авито, работа только с текстом**. Цену и доставку
не присылаем — они в текст не попадают. Бланк можно сокращать: обязательны пункты 1, 2, 5, 6.
Что неизвестно — оставляй пустым: цифры сам придумывать не буду, задам короткий вопрос.

```
1. Товар (тип, модель, бренд):
2. Исходное описание (как есть, можно копипастом от поставщика):
3. Характеристики (материал, размеры, рост, вес, цвет, класс защиты, совместимость, питание и т.п.):
4. Комплектация (что входит поштучно; чего НЕТ в комплекте):
5. Состояние (новое / б/у, следы эксплуатации):
6. Производитель и страна:
7. Документы (сертификат / декларация / информационный листок: тип, номер, срок; класс защиты по ГОСТ):
8. Маркировка «Честный знак» (есть / нет / не требуется) — для одежды, обуви, головных уборов, перчаток, ремней, СИЗ:
9. Известные нюансы и честные минусы товара:
10. Фото (сколько, есть ли снимок сертификата, есть ли на фото знаки различия, чужие логотипы или водяные знаки):
```

## Формат ответа

1. **Заголовок** — ≤ 50 символов, тип + модель + 1–2 параметра.
2. **Описание** — 800–1500 символов, без цены, без доставки, без контактов и ссылок, без эмодзи и КАПСА.
3. **Пометка по рискам** — что может не пройти модерацию и чем заменено.
4. **Счётчик символов** для заголовка и описания.

## Справка для ответов покупателям в чате (в объявление не пишем)

- Отправка только СДЭК и другими ТК по договорённости, «Авито Доставку» не используем.
- За пределы РФ, включая Беларусь, Казахстан и другие страны СНГ, а также в Калининградскую область
  форму, камуфляж, бронезащиту, шлемы, оптику и снаряжение не отправляем.
