# Карточка товара — бланк для заполнения

Текущий режим (см. `docs/04-rabochiy-rezhim.md`): **только Авито**, цена и блок доставки в текст не ставятся.
Бланк можно присылать не целиком — достаточно пунктов 1, 2, 5, 6, 9. Что неизвестно, оставляй пустым:
цифры я сам придумывать не буду, а задам короткий вопрос.

```
1. Товар (тип, модель, бренд):
2. Исходное описание (как есть, можно копипастом от поставщика):
3. Цена:
4. Наличие (сколько штук / под заказ, срок):
5. Характеристики (материал, размеры, рост, вес, цвет, класс защиты, совместимость, питание и т.п.):
6. Комплектация (что входит поштучно; чего НЕТ в комплекте):
7. Состояние (новое / б/у, следы эксплуатации):
8. Производитель и страна:
9. Документы (сертификат / декларация / информационный листок: тип, номер, срок; класс защиты по ГОСТ):
10. Маркировка «Честный знак» (есть / нет / не требуется):
11. Город самовывоза:
12. Как реально отправляем (самовывоз / ТК / Авито Доставка / Почта):
13. Условия обмена и возврата (если отличаются от стандартных):
14. Известные нюансы и честные минусы товара:
15. Фото (сколько, есть ли снимок сертификата, есть ли на фото знаки различия / чужие логотипы / водяные знаки):
16. Куда публикуем: [x] Авито  [ ] карточка ВК  [ ] пост ВК  (по умолчанию — только Авито)
```

## Формат ответа по умолчанию

1. **Авито** — заголовок (≤50 симв.) + описание 800–1500 симв., без цены, доставки, контактов и ссылок,
   без эмодзи и КАПСА.
2. **Пометка по рискам** — что в позиции может не пройти модерацию и чем заменено.
3. **Счётчик символов** для заголовка и описания.

Версии под ВК (карточка товара и пост) — только по отдельному запросу, шаблоны лежат в
`docs/03-shablony-i-primery.md`.
