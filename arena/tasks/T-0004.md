## Что сделать

Собрать регулярную передачу **«СВОДКА»** для эфира радио «В ОКОПЕ»:
короткий обзор успехов наших за прошедшие сутки, начитанный голосом,
в стиле канала. Две версии в сутки — утренняя и вечерняя.

Полное ТЗ владельца — `radio_vokope/svodka/ТЗ.md` (копия файла
`ТЗ_СВОДКА_для_чата.md`, переданного человеком 2026-11-03).

### Жёсткие параметры из ТЗ
- 1280×720 (16:9), **25 fps**, H.264 **yuv420p**, AAC 44 100 Гц, стерео, 128 кбит/с, MP4.
- Длительность **120–180 с**.
- Без водяных знаков, чужих логотипов и титров сторонних сервисов.
- Оформление: тёмно-зелёный/чёрный с золотом; сверху лого-щит и «В ОКОПЕ · РАДИО»;
  крупный заголовок «СВОДКА» и дата; тезисы появляются по мере озвучки, читаемо с телефона.
- Фон — только свободные от прав кадры (сгенерированные или сток без требований).
- Музыка — тихая, без вокала.
- Текст: 350–420 слов, «ты», спокойно и уверенно, без пафоса и канцелярита.
- Структура: заход → 5–7 фактов по одному предложению → строка «где наши работают»
  → благодарность → куда идти помогать → финал «Своих не бросаем. Радио «В ОКОПЕ».»

### Запрещено
Политика, прогнозы и оценки; потери, трагедии, гражданские жертвы; точные координаты,
номера частей и места дислокации. Имена и позывные — только официально опубликованные.

### Сдача
Имена файлов строго по ТЗ:
`svodka_YYYY-MM-DD_utro.mp4` / `.txt` / `.mp3`, для вечера — `_vecher`.
Первая строка `.txt` — «Источник: …».

## Готово, когда

Передача сдана по ссылке, проходит приёмку ТЗ (длительность, отсутствие
запрещённых тем, пересказ а не копипаста, читаемость на телефоне, файл со звуком).

## Блокеры (нужно от владельца / координатора)

1. **Источник фактов.** Песочница Arena имеет выход в сеть только на GitHub и PyPI:
   YouTube и новостные сайты недоступны. Смотреть выпуски канала я не могу.
   Нужен текст: расшифровка 1–2 выпусков **или** готовые 5–7 фактов своими словами
   (файл `radio_vokope/svodka/facts_YYYY-MM-DD.md`, пометка утро/вечер).
2. **Лого-щит.** В репозитории его нет (проверено по всему дереву). Нужен PNG
   с прозрачностью или SVG. Без него в кадре будет текстовая плашка, а по ТЗ щит обязателен.
3. **Музыка — конфликт правил.** ТЗ просит «тихую, сдержанную» подложку,
   а `video_studio/MUSIC_POLICY.md` запрещает спокойные подложки и требует драйв
   ≥120 BPM. Предлагаю: сделать для «СВОДКИ» явное исключение — новостная подложка
   −24…−20 LUFS под голосом, голос ведущий. Нужно «ок» координатора.
4. **Формат.** 16:9/720p/25 fps — отдельный движок вёрстки; вертикальная студия
   (`video_studio/*`) не переиспользуется напрямую.
5. **Папка `C:\Work\Exchange\сводка\`** — на ноутбуке владельца. Сдаю ссылками
   на GitHub с точными именами файлов; раскладку в папку делает человек.
6. **Расписание.** Автозапуска нет: каждая передача — отдельный запуск сессии.
   Реально: человек присылает факты утром и вечером, сессия собирает выпуск.
