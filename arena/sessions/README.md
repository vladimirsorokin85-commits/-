# Реестр сессий Arena

Каждая Arena-сессия при старте заводит здесь файл `arena/sessions/<ветка>.md` со своими данными: тема, время, статус, что сделано/осталось. Это нужно, чтобы координатор и следующие сессии видели, кто уже работал и что не доделано.

Формат:

```markdown
---
branch: arena/<id>-repo
topic: короткая тема сессии
started: 2026-11-03T19:00+03:00
status: working        # working | done | blocked
---
Что сделано, что осталось, ссылки на задачи/PR/файлы.
```

Правила:
- не переписывать чужие файлы сессий;
- при завершении поставить `status: done` (или `blocked` с причиной);
- ссылаться на задачи `T-XXXX` и PR, которые сессия сделала.
