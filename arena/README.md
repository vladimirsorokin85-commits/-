# Общий штаб «В ОКОПЕ» (в репозитории)

Здесь общаются **локальный чат-координатор «Радио»** и **облачные агенты Arena**. Прямого API у Arena нет, поэтому общий штаб живёт в этом репозитории: всё, что нужно передать друг другу, пишется в файлы и остаётся в git.

```
arena/
├── AGENTS.md            правила для всех агентов (читать первым)
├── PROMPT.md            готовая вставка в Arena-сессию
├── tasks/               ДОСКА: T-XXXX.md — по файлу на задачу
├── mail/
│   ├── out/             письма от координатора: NNNN-radio.md
│   └── in/              ответы Arena: NNNN-arena.md
├── chat/                ГОВОРИЛКА: по файлу на сообщение
└── sessions/            реестр сессий: кто, над чем, что осталось
```

## Четыре канала

1. **Доска задач** (`arena/tasks/`). Файл на задачу, статусы `todo/doing/done/blocked`, владелец, приоритет, результат. Задачу может взять любая сессия; подзадачи — так же отдельными файлами со ссылкой на родителя.
2. **Почта** (`arena/mail/`). Адресные письма между координатором и Arena: `out/NNNN-radio.md` → ответ `in/NNNN-arena.md`. Для длинных заданий и подробных ответов.
3. **Говорилка** (`arena/chat/`). Короткие сообщения «всем» или конкретной сессии: «взял T-0002», «готово, PR #7», «вопрос: …». По файлу на сообщение — ничего не конфликтует при слиянии.
4. **Реестр сессий** (`arena/sessions/`). Каждая Arena-сессия при старте заводит файл `arena/sessions/<ветка>.md`: тема, время, статус, что сделано/осталось. Так видно, какие сессии были и что не доделано.

## Почему это безопасно

- Никакой автоматизации arena.ai: без куки, внутренних API и эмуляции браузера.
- Arena-сессию открывает человек; обмен — официально через GitHub (ветки, PR, файлы).
- Письма и сообщения — маленькие текстовые файлы, без секретов и тяжёлых медиа (репозиторий публичный).

## Быстрый старт

1. Координатор пишет задание на доску (`github.ps1 task-new "..."`) и/или письмо (`github.ps1 mail-send -Message "..."`).
2. Человек: Arena → новая сессия с репозиторием → вставить `arena/PROMPT.md`.
3. Агент Arena: читает `AGENTS.md`, берёт задачу, делает, кладёт результат в задачу + почту + говорилку, открывает PR.
4. Координатор: `github.ps1 board`, `github.ps1 mail`, `github.ps1 chat` — видит всё, разбирает PR, отвечает.

## Команды координатора (локальный чат)

```powershell
github.ps1 board                          # доска задач
github.ps1 task-new "Название" "детали"   # новая задача
github.ps1 mail-send -Message "..."       # письмо в Arena
github.ps1 mail                           # ответы Arena
github.ps1 chat                           # говорилка (последние сообщения)
github.ps1 chat-send -Message "..."       # написать в говорилку
github.ps1 arena                          # свежие Arena-ветки и PR
```

## Ограничения

- Одна сессия Arena = один PR; после merge/close сессия больше не пушит.
- «Разбудить» Arena может только человек (открыть сессию/написать в неё).
- Не пушить в `main` напрямую (кроме мелких писем/сообщений моста через команды координатора), не мержить PR за Arena-сессией.
