## 1. niche-hook-miner — валидация ниши и хуки

**Как применять для «В Окопе»:**

Метод считает нишу по четырём сигналам. Ниже — адаптированные критерии под военную тематику:

| Сигнал | Как считать для «В Окопе» | Ожидаемый результат |
|--------|---------------------------|---------------------|
| **Small-account breakout rate** | Сколько каналов с ≤ 20 000 подписчиков имеют видео с ≥ 10 000 просмотров за последний месяц по темам: маскировка от тепловизора, защита от FPV, чулок на прицеле, пенофол в блиндаже. | Если ≥ 5 таких видео — ниша работает для малых игроков (BLUE OCEAN / CONTESTED, но не RED OCEAN). |
| **HHI creator concentration** | Доля топ-3 каналов (Военные Сводки, WarLeaks и др.) от общего объёма просмотров по запросу «военные лайфхаки». | Если концентрация ниже 60 %, есть место для нового игрока. |
| **Demand freshness** | Количество новых видео за 7 дней по ключевым словам «защита от FPV», «пенофол блиндаж», «чулок на прицеле». | Рост запросов = актуальная ниша. |
| **Format gaps** | Есть ли видео по теме, но без субтитров, без четкого хука, без демонстрации товара в полевых условиях. | Пробел = возможность сделать лучше конкурентов. |

**Готовые хуки для «В Окопе»** (6 структур из скила):

1. **Negative** — «Не кладите пенофол снаружи блиндажа — сгорите от тепловизора»
2. **Contrarian** — «Защита от дронов не нужна — нужна правильная сетка»
3. **Curiosity gap** — «Чулок за 50 ₽ против бленды за 3000 ₽: кто выиграл»
4. **Callout** — «Боец, ты покупаешь подделку? Проверь V50 перед заказом»
5. **Result-first** — «Как скрыться от тепловизора за 2000 рублей»
6. **Warning** — «Три документа без которых бронепленку брать нельзя»

## 2. yt-meta — сбор метаданных конкурентов

**Установка и использование:**

```bash
npm install -g yt-meta-cli
```

**Команды для «В Окопе» (без API-ключа):**

```bash
# Метаданные одного видео конкурента
yt-meta video "https://www.youtube.com/watch?v=XXXXXXXXXXX"

# Информация о канале + его последние видео
yt-meta channel @militarySummary_ru --videos --limit 50

# Поиск видео по ключевым словам военной ниши
yt-meta search "защита от FPV дронов" --limit 30
yt-meta search "пенофол блиндаж тепловизор" --limit 30
yt-meta search "чулок на прицеле антиблик" --limit 30
yt-meta search "маскировка от тепловизора СВО" --limit 30

# Комментарии к успешному видео — узнать, что пишут люди
yt-meta comments VIDEO_ID --limit 100
```

**Что выгружать в таблицу (CSV):**
- video_id, title, views, likes, upload_date, duration, channel, tags, thumbnail_url
- Далее отсортировать по views, отфильтровать за последние 30–90 дней, выявить повторяющиеся темы в заголовках.

## 3. Shorts_Tracker — мониторинг каналов в дашборде

**Установка:**

```bash
git clone https://github.com/svllvsxprod/Shorts_Tracker.git
cd Shorts_Tracker
pip install -r requirements.txt
# настройка .env по .env.example
docker-compose up -d
```

**Как применять:**

- Добавить в отслеживание каналы: `@militarySummary_ru`, `@WarLeaks`, каналы по обзору军事-снаряжения, каналы волонтёров.
- Дашборд покажет динамику просмотров, Engagement, лучшие форматы за неделю/месяц.
- Еженедельно смотреть, какие темы растут, и добавлять их в свой контент-план.

## 4. reel-intel — разбор структуры и транскриптов конкурентов

**Как применять:**

- Скачать успешный Shorts конкурента (через скил 5 или yt-dlp).
- Пропустить через `reel-intel` для получения точной транскрипции и временных меток.
- Выяснить:
  - За какую секунду происходит хук?
  - Какая структура повествования (проблема → решение → демонстрация → CTA)?
  - Как часто меняются сцены?
  - Какие звуковые акценты используются?
- Перенести структуру на свою тему: например, «чулок на прицеле» с той же ритмикой, но своими товарами «В Окопе».

## 5. youtube-shorts-downloader-python — скачивание примеров Shorts

**Использование:**

```bash
wget https://raw.githubusercontent.com/mikesmith-ge/youtube-shorts-downloader-python/main/youtube_downloader.py
chmod +x youtube_downloader.py

# Скачать конкретный Shorts конкурента
python youtube_downloader.py "https://youtube.com/shorts/XXXXXXXXXXX"

# Пакетная загрузка по списку URL
python youtube_downloader.py "https://youtube.com/shorts/URL1"
python youtube_downloader.py "https://youtube.com/shorts/URL2"
```

**Для «В Окопе»:** собрать папку с 10–20 успешными военными Shorts (маскировка, дроны, лайфхаки), разобрать их montage, хук, субтитры, длительность, и снять свои варианты по этой же формуле.

## 6. youtube-outliers — поиск аномальных видео

**Метод (marianina8/youtube-outliers, без API для поиска по ключевым словам):**

1. Собрать список ключевых слов военной нише (см. `MILITARY_KEYWORDS.txt`).
2. Поискать по каждому ключевому слову до 25 видео.
3. Оставить только каналы с ≤ 20 000 подписчиков (малые игроки, которые могут «выстрелить»).
4. Оставить видео с ≥ 10 000 просмотров.
5. Вычислить `views / subscribers ≥ 3×` и `views / day`.
6. Экспорт в CSV → анализ паттернов: какие заголовки, обложки, первые 3 секунды работают.

**Готовый Python-скрипт для поиска outliers (на базе yt-dlp, без API-ключа):** см. файл `find_outliers.py` в репозитории.

## Интегрированный workflow для «В Окопе»

```
Этап 1. niche-hook-miner — проверить, не переполнена ли ниша «военные лайфхаки»
        ↓
Этап 2. yt-meta + youtube-outliers — собрать каналы, найти аномальные видео
        ↓
Этап 3. youtube-shorts-downloader — скачать топ-10 аномальных Shorts
        ↓
Этап 4. reel-intel — расшифровать их структуру и хуки
        ↓
Этап 5. Shorts_Tracker — отслеживать динамику по выбранным каналам
        ↓
Этап 6. Снять свои Shorts по тем же хукам, но под товары «В Окопе»
        ↓
Этап 7. Опубликовать, замерять CTR + удержание, масштабировать заход
```
