## Повторить сборку

Из `video_studio/drone_cartoon` с Node.js 20+, FFmpeg и Python 3 с NumPy:

```sh
npm ci
npm test
npm run render:gongtex
npm run preview
```

Рендер создаёт `output/gongtex-reversible.mp4`, `output/gongtex-reversible.jpg` и звуковой мастер в `output/`. Черновой размер 540 × 960: `npm run render:gongtex -- --draft`. `preview` использует свежий рендер, а если его нет — сохранённый MP4 и обложку. Сборка не публикует ролик в соцсети.
