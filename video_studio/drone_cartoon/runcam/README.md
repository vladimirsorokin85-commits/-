## Источники и уточнения

- [Карточка RunCam](https://runcam.com/products/runcam-helmetcam2) и [официальная инструкция](https://dl.runcam.cn/runcam/download/helmetcam2/Helmetcam2_Manual_en.pdf), разделы 1.1, 2.2–2.4 и 06: Full HD, f/1.6, сменный 18650, автостарт, вибрация, Wi-Fi, предпросмотр. В инструкции автостарт записи происходит после запуска, примерно через 8 с; «мгновенная запись» не заявлена. Фактической съёмки в темноте нет, инфракрасное видение не обещается.
- В спецификации RunCam около 8 ч при 1080p60 и батарея 3 500 мА·ч. В тексте владельца — 2 000 мА·ч. Метки ёмкости на предоставленных фото не видны. В ролике число часов относится только к условиям производителя, а не к тесту партии или заявлению о поставляемой ёмкости.
- Вместо не подтверждённого официальной инструкцией класса IP67 — общий текст о пыли и брызгах. Никаких обещаний погружения. Цены и складские остатки не добавлены. Комплект показан по фото владельца, без обещаний о количестве неразличимых на снимках крепёжных деталей.
- В `assets/` уменьшенные JPEG без метаданных. Соответствие фото 1–9: `box`, `controls`, `base`, `power`, `kit-top`, `lens`, `camera`, `open-box`, `kit-angle`. Логотип магазина — `../bulat/assets/v-okope-white.png`.
- Пять русских реплик в `../vo/runcam-*.mp3`; `vo_text.txt` хранит текст для озвучки. Музыка — фрагмент точного MP3 владельца `StockTune-Storm Riders Unleashed_1794986419.mp3` с 0:55,154, без изменения темпа (~174,05 BPM). Эффекты из `video_studio/toolkit/sfx`. `music_check`: «ДРАЙВ», суб 22,0%, низ 36,3%; AAC после экспорта: −14,0 LUFS и −2,4 dBTP.

## Собрать заново

Из `video_studio/drone_cartoon` с Node.js 20+, FFmpeg и Python 3 с NumPy:

```sh
npm ci
npm test
npm run render:runcam
npm run preview
```

Сборка сохраняет `output/runcam-helmet-2.mp4`, `output/runcam-helmet-2.jpg` и звуковой мастер. Черновик: `npm run render:runcam -- --draft`. Если сборки нет, плеер использует сдаваемый MP4 и сохранённую обложку. Ролик не опубликован в соцсетях.
