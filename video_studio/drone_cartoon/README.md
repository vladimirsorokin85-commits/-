# Мультфильм «Знать вовремя»

30-секундный рисованный ролик об автоматическом оповещении о дронах на гражданском объекте. Неизвестный дрон появляется над промзоной, детектор отправляет уведомление ответственному за безопасность. В финале — магазин «В Окопе» и автоматические детекторы дронов.

Все кадры рисуются кодом. В звуковой дорожке — русская озвучка, барабанный трек Kevin MacLeod **Beat One** (162 BPM, мастер из `music_downloaded/`, с пометкой Free PD) и эффекты из [`toolkit/sfx`](../toolkit/sfx/LICENSE.txt). Под голосом музыка автоматически приглушается. Мастер: −14 LUFS, целевой true peak −1,8 dBTP до кодирования AAC.

- [Первая версия «Дрон над объектом»](./v_okope_dron_nad_obektom.mp4) — отдельный ролик на 24 секунды.

## Собрать заново

Нужны Node.js 20+ и Python 3 с NumPy для проверки музыкального мастера. Системный FFmpeg с `libx264` используется, если он есть; иначе сборка использует платформенный бинарник из опциональной зависимости npm. Свой бинарник можно указать через `FFMPEG_BIN`, интерпретатор Python — через `PYTHON`.

```sh
cd video_studio/drone_cartoon
npm ci
npm test
npm run render
npm run preview
```

Плеер открывается на `http://localhost:8000` (порт можно изменить через `PORT`). Предпросмотр использует свежий рендер, а если его нет — готовый MP4 из репозитория. Экспорт сохраняет `output/znat-vovremya.mp4` (1080 × 1920, 30 кадров/с, H.264 + AAC), JPEG обложки и аудиомастер. Для прогона 540 × 960 используйте `npm run render -- --draft`. Промежуточные файлы `output/` не входят в Git.
