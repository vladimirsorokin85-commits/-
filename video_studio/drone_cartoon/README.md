# Мультфильм «В своём ритме»

30 секунд рисованной анимации. Детектор замечает неизвестный дрон на подлёте, и уведомление автоматически получает ответственный за безопасность. В цехе продолжается обычный день. Кот не отвлекается до обеда.

Русский диктор и готовый, скачанный jungle / drum and bass **Final Hour** от isaiah658, **170 BPM**, [CC0 1.0 и происхождение файла](../music_downloaded/FINAL-HOUR-CREDITS.md). Монтаж привязан к сетке трека. Музыка приглушается под диктором и возвращается вперёд в паузах; фон не генерировался. Эффекты — из [`toolkit/sfx`](../toolkit/sfx/LICENSE.txt).

## Собрать заново

Нужны Node.js 20+ и Python 3 с NumPy для проверки музыкального мастера. Системный FFmpeg с `libx264` используется, если он есть; иначе сборка использует платформенный бинарник из опциональной зависимости npm. Свой бинарник можно указать через `FFMPEG_BIN`, интерпретатор Python — через `PYTHON`.

```sh
cd video_studio/drone_cartoon
npm ci
npm test
npm run render
npm run preview
```

Плеер открывается на `http://localhost:8000` (порт можно изменить через `PORT`). Он использует свежий рендер или, если его нет, готовый MP4 из репозитория. Экспорт сохраняет `output/v-svoem-ritme.mp4`, JPEG обложки и звуковой мастер. Для прогона 540 × 960 используйте `npm run render -- --draft`. Промежуточные файлы `output/` не входят в Git.
