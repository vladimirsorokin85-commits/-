# Мультфильм «Дрон над объектом»

24-секундный вертикальный мультфильм о том, как дежурная реагирует на неизвестный дрон над гражданским центром «Маяк» и какую роль в защите объектов играет РЭБ. Без инструкций по применению РЭБ. Финальная карточка называет «В Окопе» магазином.

Все кадры рисуются кодом: здание, дрон, персонаж, титры, текстура бумаги и переходы. Озвучки и музыки нет; в ключевых моментах слышны эффекты из [`toolkit/sfx`](../toolkit/sfx/LICENSE.txt). Все реплики переданы титрами.

## Посмотреть и скачать

[Готовый видеофайл MP4](./v_okope_dron_nad_obektom.mp4) — 24 секунды, 1080 × 1920. Для просмотра или скачивания пересобирать проект не нужно. На странице файла в GitHub нажмите **Download raw file**.

В открытом предпросмотре также доступны кнопки **Смотреть** и **Скачать MP4**, переходы по сценам и текст титров.

## Собрать заново

Нужен Node.js 20 или новее. Системный FFmpeg с `libx264` используется, если он есть; иначе сборка использует бинарник из опциональной зависимости npm. Путь к своему бинарнику можно задать переменной `FFMPEG_BIN`.

Из корня репозитория:

```sh
cd video_studio/drone_cartoon
npm ci
npm test
npm run render
npm run preview
```

Локальный плеер открывается на `http://localhost:8000` (порт можно изменить через `PORT`). Сборка создаёт `output/dron-nad-obektom.mp4` (1080 × 1920, 30 кадров/с, H.264 + AAC) и `output/cover.jpg`. Для быстрой проверки можно выполнить `npm run render -- --draft`: получится отдельный MP4 540 × 960. Файлы `output/` не входят в Git.

| 0:00 | Дрон появляется над центром «Маяк». |

Титры и монтажные отметки находятся в `story.mjs`, рисунки и движения — в `film.mjs`, звук и экспорт — в `render.mjs`.
