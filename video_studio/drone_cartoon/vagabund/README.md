## Сверка характеристик

- [Prabos, Vagabund Ankle S80657-098](https://www.prabos.cz/vagabund-ankle2-en): высота 14,5 см, **620 г за один ботинок 42-го размера**, DRI-LEX PES+PA без мембраны, подошва PHOBOS PU/резина двойной плотности, вставка от проколов и EN ISO 20347 O3 CI HRO SRC. Данные модели, не замер и не сертификация снятой пары.
- [Vagabund Ankle Field S80657-098 в каталоге «Воин»](https://voinmarket.com/catalog/product/botinki_vagabund_ankle_field_prabos_tsvet_samouflage/): совпадают ракурсы обуви и описание кевларовой вставки. Для итогового монтажа использованы только присланные изображения.
- Наличие и доставка СДЭК по России взяты из текста владельца. Нет цен, размера складского остатка или нового объявления в соцсетях.

## Сборка

```sh
cd video_studio/drone_cartoon
npm ci
npm run render:vagabund
npm test
npm run preview
```

Нужны Node.js 20+, FFmpeg с H.264, Python 3 с NumPy. Для повторной подготовки прозрачных вырезок: `node vagabund/prepare.mjs /путь/к/трём/фото`. Сборка использует уже подготовленные вырезки и четыре русские реплики из `vo/`. Монтажные точки приведены к 174,05 BPM; исходная запись — `StockTune-Storm Riders Unleashed_1794986419.mp3`, отрезок с 00:55,154 на оригинальной скорости. Переходы используют [студийные SFX](../../toolkit/sfx/LICENSE.txt). В `output/` создаются `prabos-vagabund-ankle.mp4`, JPEG и `master-prabos-vagabund-ankle.wav`.
