# «Game Over для дрона» — сценарий №2

[Готовый MP4](../v_okope_game_over.mp4) · 30 секунд, 1080 × 1920, 30 кадров/с. Отдельный ролик; [«В своём ритме»](../v_okope_v_svoem_ritme_montazh.mp4) не заменён.

Вертикальная аркада с вымышленной low-poly промзоной. HUD показывает только номера планов и время сцены. `GAME OVER` — конец игрового уровня, не демонстрация отключения или повреждения дрона. После него ролик переходит к местному звуковому сигналу детектора и общему плану объекта.

| Время | Кадр |
| --- | --- |
| 00:00–00:06 | POV игровой камеры: склад, площадка, офис. Голос из игры звучит через эффект рации. |
| 00:06–00:13 | Пиксельный переход, короткий сигнал, экран `GAME OVER`. |
| 00:13–00:22 | Тёплая панорама промзоны, спокойная озвучка и более открытый бит. |
| 00:22–00:25 | Три коротких плана: спецтехника, склад и офис. |
| 00:25–00:30 | Магазин «В Окопе», слоган «Не будь мишенью. Будь „В окопе“!» и QR-коды Telegram, ВКонтакте и Авито. |

Трек: [Storm Riders Unleashed, StockTune](https://stocktune.com/free-music/storm-riders-unleashed-59750-53368), тот же [загруженный владельцем MP3](../../../StockTune-Storm%20Riders%20Unleashed_1794986419.mp3). Вторая роль записана отдельным голосом `ru-RU`. [Лицензия монтажных эффектов](../../toolkit/sfx/LICENSE.txt).
