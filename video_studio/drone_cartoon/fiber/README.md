# Оптоволокно G.657.A2 — намотка и маркировка

[Вертикальный MP4](../v_okope_fiber_g657a2.mp4) · [обложка](./assets/cover.jpg) · [заголовок и описание](./publish.txt). Плеер `/fiber-g657a2/`.

## Что в кадре

29 секунд, 9:16. По дизайн-референсу композицию задаёт предмет: одна линия входит в виток по контуру реальной катушки. Овал раскрывает следующий крупный план. Две краски — зелёная и малиновая — на тёплой бумаге; фактура и цвет исходных фотографий сохранены. Линия — графический приём, не показ размотки или подключения.

| Начало | План |
| ---: | --- |
| 00:00 | Катушка и заголовок |
| 00:03,10 | G657A2 на этикетке; что означает категория |
| 00:08,63 | 0,25 мм по карточке, открытый футляр |
| 00:13,80 | Крупный план намотки |
| 00:17,23 | 50,4 км по карточке |
| 00:22,07 | 51,395 км на этикетке одной катушки; оба значения подписаны |

- Прозрачность и диаметр 0,25 мм — из карточки владельца, не собственный замер. G657A2 на этикетке соответствует записи категории `G.657.A2` в [ITU-T G.657 (08/2024), §6](https://www.itu.int/rec/T-REC-G.657-202408-I/en) для одномодового оптоволокна. Обзор не подтверждает результаты испытаний этой партии.
- Длина позиции в карточке — **50,4 км**. Крупный план этикетки (`Len: 51.395km`) относится к одной снятой катушке. Это не замер и не длина каждой катушки; два значения в ролике не подменяют друг друга.
- Использованы все четыре фото владельца: №1 с открытым футляром, №2 с намоткой, №3 с этикеткой, №4 с катушками сверху. Для второго и последнего планов оставлены нужные строки этикетки; QR и серийные идентификаторы в кадре не читаются. Без демонстрации применения, цен и контактов.

## Сборка

```sh
cd video_studio/drone_cartoon
npm ci
npm run render:fiber
npm test
npm run preview
```

Требования: Node.js 20+, FFmpeg с H.264, Python 3 с NumPy. Экспорт: `output/fiber-g657a2.mp4`, `output/fiber-g657a2.jpg` и `output/master-fiber-g657a2.wav`. Три русские реплики сведены с точным `StockTune-Storm Riders Unleashed_1794986419.mp3` владельца (фрагмент с 00:55,154 на исходной скорости). Переходы привязаны к биту.
