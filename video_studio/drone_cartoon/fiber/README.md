# Оптоволокно G.657.A2 на складе

[Вертикальный MP4](../v_okope_fiber_g657a2.mp4) · [обложка](./assets/cover.jpg) · [заголовок и описание](./publish.txt). Плеер `/fiber-g657a2/`.

## Повествовательная версия

31 секунда, 9:16. Рассказ от лица владельца: что лежит на складе, как катушка выглядит в футляре и что видно под плёнкой. Диктор ведёт зрителя по фотографиям от упаковки к намотке и этикетке. Сравнение длин и разбор характеристик из первого монтажа убраны.

| Начало | План |
| ---: | --- |
| 00:00 | Что у нас на складе: оптоволокно |
| 00:04,83 | Катушки в футлярах |
| 00:08,97 | Открытая катушка под плёнкой |
| 00:14,83 | Намотка крупным планом |
| 00:19,30 | G657A2 на этикетке |
| 00:23,80 | Возвращение к общему виду в футляре |
| 00:27,23 | Пэкшот с катушками и лозунгом `Не будь мишенью. Будь «В окопе»` |

Использованы все четыре фото владельца: открытый футляр, макро намотки, этикетка и ракурс сверху. На этикетке в крупном плане оставлено только обозначение волокна. Виток в печатной графике связывает планы. Финальный пэкшот остаётся на экране 3,5 секунды после перехода; дополнительной реплики нет. Это фотообзор товара, а не съёмка помещений склада.

## Сборка

```sh
cd video_studio/drone_cartoon
npm ci
npm run render:fiber
npm test
npm run preview
```

Требования: Node.js 20+, FFmpeg с H.264, Python 3 с NumPy. Экспорт: `output/fiber-g657a2.mp4`, `output/fiber-g657a2.jpg` и `output/master-fiber-g657a2.wav`. Три новые русские реплики сведены с точным `StockTune-Storm Riders Unleashed_1794986419.mp3` владельца (фрагмент с 00:55,154 на исходной скорости). Переходы привязаны к биту.
