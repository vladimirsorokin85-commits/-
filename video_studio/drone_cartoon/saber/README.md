## Фотографии и сверка

Из десяти присланных снимков восемь уникальны: №4 = №9 и №5 = №8. В `assets/` — подготовленные кадры: `stack` (1), `black` (2), `case` (3), `box` (4), `tan` (5), `olive` (6), `label` (7), `group` (10). Футляр и разложенные принадлежности показаны с разных снимков владельца.

Цвет оправы отделён от оттенка линзы. Официальные страницы Wiley X для комплектов [308 / Matte Black](https://wileyx.eu/products/saber-advanced-308), [308G / Matte OD Green](https://www.wileyx.com/products/saber-advanced-308g) и [308T / Matte Tan](https://wileyx.eu/products/saber-advanced-308t) использованы для сверки названий, сменных линз и регулировок. Размеры и сертификационные обещания не перенесены в монтаж: параметры зависят от артикула, а фотографии не подтверждают происхождение или защитные свойства конкретного экземпляра.

## Сборка

```sh
cd video_studio/drone_cartoon
npm ci
npm run render:saber
npm test
npm run preview
```

Нужны Node.js 20+, FFmpeg с H.264 и Python 3 с NumPy. Экспорт: `output/wiley-x-saber-advanced.mp4`, JPEG и `output/master-wiley-x-saber-advanced.wav`. Четыре русские реплики записаны выбранным голосом. Музыка — отрезок с 00:55,154 точного `StockTune-Storm Riders Unleashed_1794986419.mp3` владельца на исходной скорости. Склейки синхронизированы с долями этой записи; эффекты переходов — [из библиотеки студии](../../toolkit/sfx/LICENSE.txt).
