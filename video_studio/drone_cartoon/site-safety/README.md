## Сборка

Из `video_studio/drone_cartoon`: `npm run render:site-safety` (проба: `npm run render:site-safety -- --draft`). Нужны Node.js, Python с NumPy и FFmpeg — [подробности](../README.md#собрать-заново). Обе короткие видеовставки уже подготовлены; оригиналы для сборки не нужны. `npm run preview` обслуживает свежий рендер или готовый MP4 из проекта. Промежуточные файлы остаются в `output/`.
