## Монтаж

28 секунд, 9:16. Приём из предоставленного дизайн-референса: предмет сам задаёт композицию. V-образный рельеф на крышке кейса становится прорезью между кадрами. Его же контур работает как трафарет для крупного плана кожуха и как печатный оттиск за фотографиями. Две краски (синяя и красная), тёплая бумага с зерном, асимметрия и крупная типографика вместо карточек или фоновых эффектов. Фотографии не выданы за съёмку работающего изделия.

Корпус из анодированного алюминия, пластиковый кожух, 330 × 300 × 70 мм и 4,05 кг указаны по карточке владельца, не как проверенные замеры. Использованы четыре предоставленные фотографии: внешний вид блока (№7), крышка кейса (№1), ложемент (№8), обложка техпаспорта (№9). В исходниках только нужные кадрирования. Не показываем подключение или применение, нет цен, контактов и рабочих характеристик радиотракта.

## Воспроизведение сборки

```sh
cd video_studio/drone_cartoon
npm ci
npm run render:incubator
npm test
npm run preview
```

Требования: Node.js 20+, FFmpeg с H.264, Python 3 с NumPy. В `output/` — `incubator-330.mp4`, `incubator-330.jpg` и `master-incubator-330.wav`; черновик можно собрать с `-- --draft`. Три реплики на русском и исходный MP3 владельца `StockTune-Storm Riders Unleashed_1794986419.mp3` (фрагмент с 00:55,154, без изменения темпа). Склейки на исходной сетке ударных; звуки бумаги — студийные [SFX](../../toolkit/sfx/LICENSE.txt), а не звук устройства.
