# Reels Studio — вертикальные ролики от 1 до 20 минут

Новый универсальный сценарий сборки для этого репозитория. Он не привязан к ролику «Окопная смекалка» и заменяет прежний фиксированный демо-рендер на 42 секунды, если нужен длинный вертикальный выпуск.

## Что делает

- собирает MP4 **9:16** (по умолчанию 1080×1920, 30 fps);
- берёт длительность из дикторской дорожки — допустимый итоговый диапазон **1–20 минут**;
- раскладывает изображения как динамичные планы с мягким Ken Burns zoom, видеофрагменты — как есть;
- циклически повторяет список визуалов, пока он не покроет аудиодорожку;
- принимает необязательную фоновую музыку, приглушает её во время речи и задаёт цели мастеринга −14 LUFS / −1 dBTP;
- принимает SRT: субтитры можно вшить в кадр (по умолчанию) либо добавить отдельной дорожкой;
- после экспорта проверяет MP4 через ffprobe (размер кадра, fps, H.264/AAC, длительность) и сохраняет QC-отчёт;
- опционально кадрирует по лицу/фигуре, а при неуверенном распознавании сохраняет весь кадр на размытой подложке;
- пишет JSON-таймлайн для проверки длительности, смены кадров и точек фокуса.

Для основной сборки Python-зависимостей нет: нужны `ffmpeg` и `ffprobe` в `PATH`. Для вшивания субтитров нужна сборка FFmpeg с `libass`/фильтром `subtitles`; без неё используйте режим `soft`. Распознавание речи (`requirements-asr.txt`) и smart crop (`requirements-smartcrop.txt`) — опциональные зависимости.

## Быстрый старт

1. Установите FFmpeg и проверьте команды `ffmpeg -version` и `ffprobe -version`.
2. Скопируйте дикторскую дорожку длительностью 1–20 минут в `video_studio/reels/narration.wav` (либо укажите свой путь в проекте).
3. Откройте `project.example.json`. Путь к визуалам уже указывает на `video_studio/assets/*.jpg`; замените его или добавьте свои изображения/видеофрагменты.
4. Переименуйте пример в `project.json` (или передайте ему своё имя) и запустите из корня репозитория:

```bash
python3 -m video_studio.reels video_studio/reels/project.example.json --dry-run
python3 -m video_studio.reels video_studio/reels/project.example.json
```

Файлы появятся в `video_studio/reels/output/`: `reel.mp4`, `reel.timeline.json` и `reel.qc.json` (отчёт проверки экспорта). Если указать аудио короче минуты или длиннее 20 минут, сборка остановится с понятной ошибкой. Длинную запись можно намеренно обрезать, задав в проекте `duration_seconds` от 60 до 1200, но значение не может быть длиннее исходной дорожки.

После рендера запустите `python3 server.py`: в превью появятся вертикальный ролик и ссылка на скачивание. Если output переименован/перемещён, задайте `REEL_PATH=/путь/к/файлу.mp4`.

## Проект JSON

Пути считаются **от папки JSON-файла**. `visuals` принимает отдельные файлы, glob-маски (`media/*.jpg`) или папку. Порядок файлов из glob/папки — по имени. Допустимые расширения изображений: JPG, PNG, WebP, BMP, TIFF; видео: MP4, MOV, M4V, MKV, WebM, AVI.

```json
{
  "title": "Выпуск 01",
  "audio": "media/narration.wav",
  "visuals": [
    {"path": "media/stills/*.jpg", "focus": [0.62, 0.45]},
    {"path": "media/broll/closeup.mp4", "start_seconds": 2.5, "duration_seconds": 8},
    {"path": "media/broll/loop.mp4", "loop": true, "duration_seconds": 12}
  ],
  "music": "media/music.mp3",
  "captions": "captions.srt",
  "output": "output/reel.mp4",
  "duration_seconds": null,
  "settings": {
    "resolution": [1080, 1920],
    "fps": 30,
    "shot_seconds": 4,
    "chunk_scenes": 12,
    "crf": 20,
    "preset": "medium",
    "music_gain": 0.12,
    "caption_mode": "burn",
    "smart_crop": false
  }
}
```

- Для изображения без `duration_seconds` используется `shot_seconds` (1–10 сек, по умолчанию 4). Изображения мягко приближаются/отдаляются, точка кадрирования настраивается через `focus: [x, y]` от `0` до `1`.
- Видео без `duration_seconds` проигрывается от `start_seconds` до конца исходного клипа. Параметр `loop: true` разрешает зациклить видео, если заданный план длиннее источника.
- В элементе `visuals` можно указать `fit_mode: "blur"`, чтобы целиком показать исходный кадр поверх размытого фона — полезно для квадратных и широких предметных фото. По умолчанию используется `crop`; явный `fit_mode` также имеет приоритет над smart crop.
- `settings.smart_crop: true` включает необязательный subject-aware фокус через существующий `video_studio/toolkit/smartcrop.py`: лицо/фигура кадрируются крупнее, а при одном лишь saliency сохраняется полный кадр на размытой затемнённой подложке. Для видео анализируется один кадр в середине выбранного фрагмента — это статичная точка фокуса, не слежение за движущимся лицом. Для движения разбейте клип на несколько записей `visuals` с разными `start_seconds`/`duration_seconds` либо задайте `focus: [x, y]` вручную. Установка: `python3 -m pip install -r video_studio/reels/requirements-smartcrop.txt`.
- Список визуалов повторяется по кругу до конца озвучки. Добавляйте достаточно разных сцен, чтобы длинный выпуск не выглядел однообразно.
- `music_gain` — линейная громкость фоновой музыки (0–1); начните с `0.08–0.15`. Сайдчейн-фильтр FFmpeg плавно прижимает её во время речи.
- `caption_mode`: `burn` — субтитры вшиваются (лучше для Reels); `soft` — отдельная MP4/SRT-дорожка; `none` — не использовать субтитры. Если `captions` не задан, режим субтитров не применяется.
- Разрешение должно быть вертикальным 9:16 и с чётными сторонами. Остальные параметры указаны в `project.example.json`.

## Субтитры: оценка или локальное распознавание

Примерный SRT по готовому тексту (без ASR):

```bash
python3 -m video_studio.reels.captions \
  --script video_studio/reels/script.txt \
  --audio video_studio/reels/narration.wav \
  --output video_studio/reels/captions.srt
```

Для синхронизации по словам можно включить локальный `faster-whisper` — аудио не отправляется в облако:

```bash
python3 -m pip install -r video_studio/reels/requirements-asr.txt
python3 -m video_studio.reels.captions \
  --transcribe \
  --audio video_studio/reels/narration.wav \
  --language ru \
  --model small \
  --device cpu \
  --output video_studio/reels/captions.srt
```

Команда создаст `.srt` и рядом `.txt` с распознанным текстом. На CPU по умолчанию используется `int8`; на совместимой NVIDIA CUDA можно указать `--device cuda --compute-type float16`. Первый запуск скачает выбранную модель. Используются word timestamps; если модель их не вернула, команда переходит на таймкоды сегментов. Ни один режим не гарантирует идеальные имена/пунктуацию: проверьте файл перед публикацией и укажите его в поле `captions` проекта.

## Настройки качества и размер

`crf=20` — хорошее исходное качество, `18` даст крупнее файл, `23–25` уменьшит размер; допустимо 16–28. `preset` управляет скоростью x264/сжатием (`fast`, `medium`, `slow` и другие x264 presets). Для рабочих исходников храните проектные медиа в локальной папке `video_studio/reels/media/` или вне Git; эта папка и выходные файлы добавлены в `.gitignore`.
