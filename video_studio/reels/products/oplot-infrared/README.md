# Материалы рилса «Оплот Infrared»

Подготовлены дикторский сценарий, озвучка и синхронизированные субтитры. Длительность MP3 — **1:33,31**.
Подача построена вокруг открытой петли: «что означает V50 и какие три документа проверить?», с короткими
фактическими блоками и CTA.

## Файлы

- `narration.mp3` — озвучка выбранным голосом.
- `script.md` — дикторский текст, монтажный план и безопасные формулировки.
- `captions.srt` — субтитры, приведённые к реальным паузам дорожки (39 реплик, 93,31 с).
- `captions.draft.srt` — исходный черновик с равномерной раскладкой по длительности, сохранён для сверки.
- `captions.alignment.json` — отчёт о синхронизации: сколько границ сдвинуто и насколько точнее стали концы предложений.
- `project.json` — конфигурация Reels Studio: 9:16, 1080×1920, смена планов каждые 3,5 с.
- `retime_captions.py` — уточнение таймкодов черновика по паузам озвучки (без ASR).
- `output/` — собранный MP4, таймлайн и отчёт QC.

## Как собрать MP4

Пять фотографий лежат рядом с `project.json` (не в подпапке `media/`) и уже прописаны в нём по именам.
Из корня репозитория:

```bash
python3 -m video_studio.reels video_studio/reels/products/oplot-infrared/project.json --dry-run
python3 -m video_studio.reels video_studio/reels/products/oplot-infrared/project.json
```

Нужны `ffmpeg` и `ffprobe` в `PATH`; для вшитых субтитров — сборка FFmpeg с фильтром `subtitles`/libass.
Все квадратные фотографии используют `fit_mode: "blur"`, чтобы не обрезать края пончо в вертикальном кадре.

Готовый файл: `output/oplot-infrared.mp4` — **1:33,3 · 1080×1920 · 30 fps · H.264 + AAC**, субтитры вшиты.

## Субтитры: черновик и синхронизация

Черновой SRT построен равномерно по числу знаков на всю длительность дорожки. Такой способ даёт
постоянный сдвиг: в замерах концы предложений отставали от реальных пауз в среднем на **0,60 с**, и внутри
реплик оказывалось 15,8 % тишины.

`retime_captions.py` уточняет только таймкоды, не меняя текст:

1. `ffmpeg silencedetect` находит паузы в `narration.mp3`;
2. границы реплик привязываются к паузам, выбор — динамическим программированием по всем границам сразу
   (позиции строго возрастают, каждая пауза используется один раз, минимальная длительность реплики — 0,45 с);
3. штраф за границу «внутри речи» выше для конца предложения, где пауза ожидается почти всегда.

Итог: медиана отставания концов предложений **0,60 с → 0,10 с**, в пределах 0,25 с встали 11 из 15 вместо 4,
тишина внутри реплик снизилась до 12,2 %. Это всё ещё оценка по акустике, а не распознавание речи:
точные таймкоды слов даёт `python3 -m video_studio.reels.captions --transcribe` (faster-whisper, модель
качается с huggingface.co). Черновик сохранён в `captions.draft.srt`, отчёт — в `captions.alignment.json`.

```bash
python3 video_studio/reels/products/oplot-infrared/retime_captions.py \
  --draft-out captions.draft.srt --report captions.alignment.json
```

## Проверка рекламных утверждений

Текст опирается только на предоставленное описание продавца. Цена, V50, температурный диапазон, заявленное
соответствие и тепловизионный эффект независимо не подтверждены. В сценарии специально нет обещаний
пулестойкости или «невидимости» — наоборот, оба тезиса явно опровергаются («V50 239 м/с не означает
универсальную защиту от любого боеприпаса», «ИК-защита — не „невидимость“»). Перед публикацией запросите
протоколы и документы на конкретную модель/комплектацию.
