# Материалы рилса «Оплот Infrared»

Подготовлены дикторский сценарий, озвучка и черновые субтитры. Длительность MP3 — **1:33,34**. Подача построена вокруг открытой петли: «что означает V50 и какие три документа проверить?», с короткими фактическими блоками и CTA.

## Файлы

- `narration.mp3` — озвучка выбранным голосом.
- `script.md` — дикторский текст, монтажный план и безопасные формулировки.
- `captions.srt` — черновые тайминги, распределённые по тексту на длительность 93,34 с; обязательно сверьте с аудио.
- `project.json` — конфигурация Reels Studio, 9:16, 1080×1920, смена планов каждые 3,5 с.

## Как собрать MP4

Изображения из чата не оказались доступны файловой системе рендера. Сохраните пять вложений в папку `media/` с именами, указанными в `project.json`, затем из корня репозитория запустите:

```bash
python3 -m video_studio.reels video_studio/reels/products/oplot-infrared/project.json --dry-run
python3 -m video_studio.reels video_studio/reels/products/oplot-infrared/project.json
```

Нужны `ffmpeg` и `ffprobe`; для вшитых субтитров — сборка FFmpeg с фильтром `subtitles`/libass. Все квадратные фотографии настроены на `fit_mode: "blur"`, чтобы не обрезать края пончо в вертикальном кадре. Для точной синхронизации замените черновой SRT результатом локального `faster-whisper` либо вручную проверьте его.

## Проверка рекламных утверждений

Текст опирается только на предоставленное описание продавца. Цена, V50, температурный диапазон, заявленное соответствие и тепловизионный эффект независимо не подтверждены. В сценарии специально нет обещаний пулестойкости или «невидимости»; перед публикацией запросите протоколы и документы на конкретную модель/комплектацию.
