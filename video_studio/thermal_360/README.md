## Решения заказчика

- **Цену не называем нигде** — ни в кадре, ни в голосе, ни в описании.
- Делаем **оба формата**: сначала вертикальный рилс (00:46), потом горизонталь (03:52).
- **Ждём видео с примером работы** — вставка 3–5 с, подпись «ПРИМЕР РАБОТЫ · ВИДЕО ЗАКАЗЧИКА».

## Честные пометки (как в «Алдан-12»)

- Реальные фото — «ФОТО», сгенерированные кадры — «ИЛЛЮСТРАЦИЯ», схемы интерфейса — «МАКЕТ».
- Студийный светлый фон на фото затемняем в рамке — иначе он выжигает кадр.
