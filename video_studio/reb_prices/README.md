## Главное про содержание

- **Цены — только розничные** (колонка «НАЛИЧИЕ» на карточках).
- Про НДС говорим словами: работаем с НДС и без, **цену с НДС считаем по запросу** —
  колонка «С НДС 22 %» в кадр не попадает.
- Главный тезис: спецдоговор с производством → цены заводские, без наценки посредников.

## Сборка

```bash
python3 build_audio_p.py          # все пять: звук + тайминги сцен
python3 render_p.py auto --still 2 13
python3 render_p.py auto --full
```

## Технические заметки (важно на будущее)

- **Шрифты:** Sofia Sans Extra Condensed и Tektur рисуют кириллическую «Д» без ножек —
  «НДС» читается как «НАС». Поэтому заголовки и таблицы набраны Oswald (он есть в брифе).
  Для «приборных» подписей Tektur оставлен — там «Д» не встречается в ключевых словах.
- Валюта «₽» есть не во всех шрифтах: в Oswald есть, в Sofia Sans нет (рисовался квадрат).
