## Конвейер

Для каждого длинного ролика: сценарий (`narration_dr.py`) → озвучка → кадры → `audio_stage` → `render_stage` (4 части, 60 fps) → склейка → заставка (`polevaya/prepend60.py`) → перекодирование → рилы из текста ролика через `reels_dr.py`.
Для коротких: сценарий → озвучка → кадры → один ролик 30–90 с.
