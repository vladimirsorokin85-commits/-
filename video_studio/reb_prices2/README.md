# РЭБ по ценам производителя · v2 (9:16)

Переделка после брака v1: в кадре нет ни одной фотографии и ни одного наложения
текста на текст. Только линейные пиктограммы, плашки и типографика.

## Как собрано

| файл | что делает |
|---|---|
| `layout.py` | палитра, шрифты, `text()` с фактической высотой строки, реестр боксов и `collisions()`, HUD, сетка, пиктограммы (van / pack / tower / moto) |
| `scenes.py` | данные прайса (23 позиции), сцены `hook` / `table` / `cats` / `outro`, тексты плашек |
| `build_audio.py` | voice-28 + драйв-трек, −14 LUFS; пишет `master_<tag>.m4a` и `timeline_<tag>.json` |
| `render.py` | сборка кадров, машинная проверка наложений, `--full` → mp4 |

## Сборка

```bash
python3 build_audio.py g auto port stat moto     # звук + тайминги сцен
python3 render.py g auto port stat moto          # проверка наложений + stills в /tmp/rp2
python3 render.py g --full                       # готовый ролик
```

`timeline_<tag>.json` не правится руками: старты сцен считаются от фактических
стартов реплик, поэтому картинка всегда совпадает со звуком.

## Правила, зашитые в код

- Только розничные цены. НДС: «с НДС и без, цену с НДС — по запросу».
- Спецдоговор с производством → заводские цены, без наценки посредников.
- Концовка обязательна: магазин «В ОКОПЕ», `@VES_nn`, Москва и Липецк, «не оферта».
- Любой текст проходит проверку `collisions()`; сборка падает, если строки пересеклись.
- Музыка — только реальные треки из `video_studio/music_downloaded/`, прошедшие
  `toolkit/music_check.py` (ДРАЙВ).
