## Сборка

```bash
python3 build_audio_k.py a b s      # озвучка + музыка + тайминги сцен
python3 render_k.py a --still 3 13  # пробные кадры в /tmp/k8
python3 render_k.py a --full        # полный mp4
```

Тайминги сцен берутся из `timeline_<tag>.json` — их пишет `build_audio_k.py`,
поэтому монтаж всегда попадает точно в старты реплик.

## Ограничения, которые соблюдены

- ТТХ только из карточки: 8 каналов · 400–1020 / 2100–2800 / 5680–5900 МГц ·
  160 Вт · 12/24 В · 20 кг · дальность подавления 50–200 м · гарантия 12 мес.
- Цены цифрами нет: «цена по запросу» (POSTING.md/QA.md против цены в публичных Reels —
  это расходится с брифом постера, где цена указана; для видео принято правило публикаций).
- В каждом ролике: «Применение — в установленном порядке»; на титрах ТТХ — «по данным производителя».
- Нет «100%», «любой дрон», «гарантированно», «официальный дилер», ссылок и цен.
- Фото — только снимки заказчика; никаких генераций изделия и чужих логотипов.
