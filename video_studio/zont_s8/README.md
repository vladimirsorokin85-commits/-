# «В ОКОПЕ» — РЭБ-рюкзак «ЗОНТ. Модель S8» (Reels 9:16)

Вертикальный динамичный Reels, 1080×1920, 30 fps, ~37 с.
Голос `voice-28`, темп 1.16–1.37×, музыка `fvi-Arpent.ogg` (duck), loudnorm I=-14.
Фото изделия вырезаны с белого фона (scipy-маска + заделка дырок), поданы на тёмной сетке с подсветкой.

| сцена | старт | тема |
|---|---|---|
| 1 | 2.40 | хук: 500 Вт за спиной |
| 2 | 8.55 | диапазон 200–5900 МГц, 10 каналов, 500 Вт, купол |
| 3 | 18.20 | автономность: 60 мин / до 24 ч, кевлар |
| 4 | 28.35 | 16 кг, габариты, комплект, финальная заставка |

Сборка: `python3 build_audio.py && python3 render_full.py`
