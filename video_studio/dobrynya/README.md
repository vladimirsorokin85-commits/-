# «В ОКОПЕ» — ДРОНОБОЙ «ДОБРЫНЯ» (АК-74 / АК-12)

Ручной технический обзор модульного дульного устройства под дробовой выстрел.
Формат: горизонталь 16:9 (1920×1080, 30 fps) + Reels 9:16 (1080×1920, 30 fps).
Голос: `voice-28` (мужской бас, темп 1.21–1.24×). Музыка: `fvi-BeatOne.ogg` (сторонний мастер, duck 0.30).

## Сборка
```bash
python3 build_audio.py        # master_horizontal_16x9.mp3 + timeline.json
python3 build_audio_reel.py   # master_reel_9x16.mp3 + timeline_reel.json
python3 render_full.py        # горизонталь
python3 render_reel_full.py   # вертикаль
```

## Ключевые факты (из материалов производителя)
5,45×39 мм; Ø24 мм; байонет или метрическая резьба 24×1,5R; насадка 750 г (АК-74) / 800 г (АК-12); картридж 135 г; конструкционная сталь, воронение; инициирование штатным боевым патроном; после выстрела остаётся на стволе, автоматический огонь не страдает; до 200 дробин; патрон ПсГс; бронебойные и ПпГс запрещены; навеска 3,1–3,2 г; фасовка кратно 15 шт.

Цены не публикуются.
