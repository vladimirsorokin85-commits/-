# S02E01 — «Премиальная вонь»

Самостоятельная премьера второго сезона. История о двенадцати насосах из закрытого орбитального спа, где продажа близости по минутам соседствует с бордельной бухгалтерией, счетами за уборку для секс-работников и контролируемым внеземным аэрозолем из реестра. Тон — взрослая грязная космическая чёрная комедия; смена тона проявляется через поступки, реплики и циничные последствия, а не через длинное объяснение зрителю.

## Материалы

- `STORY_OUTLINE.md` — двигатель сделки, причинность, этические рамки и пределы знания.
- `script.md` — русскоязычный сценарий по отдельным репликам, пригодный для разбора `mix_stream.py`.
- `VOICE_MAP.md` — равные соведущие Бульк `voice-07` и Мявскис `voice-08`; Лот `voice-05` сообщает только проверяемые данные.
- `ART_STYLE.md`, `IMAGE_SHOTLIST.md` — визуальный канон и план кадров; людей, клиентов и дополнительных персонажей не добавлять.
- `UPLOAD_METADATA.md` — YouTube-заголовок, описание, главы-план и обязательная ссылка DonationAlerts.
- `mix_stream.py`, `build_subtitles.py`, `build_chapters.py`, `build_episode_video.py`, `package_video.py`, `qc_episode_media.py`, `build_full_release.py`, `requirements-qc.txt`, `frame_acts.json` — производственный комплект S02E01, включая финальную проверку WebRTC VAD активной речи.
