# Серия 2 — производство

Рабочее название: «Коробка, которую уже возвращали».

- `script.md` — 22 сцены; Бульк прямо обозначен как инопланетянин.
- `VOICE_MAP.md` — таблица нового распределения голосов.
- `voice2/` — отдельные голосовые фрагменты Opus (сцены 1–10 из 22 готовы).
- `images/` — вертикальные иллюстрации с нечеловеческим образом Булька.
- `reels/` — два готовых вертикальных MP4, SRT, подписи и скрипт рендеринга.
- `PRODUCTION_STATUS.md` — текущий статус и оставшиеся шаги.

Пилот и его мастер-аудио остаются без изменений.
