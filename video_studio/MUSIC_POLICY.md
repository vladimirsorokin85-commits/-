# ПОЛИТИКА ПО МУЗЫКЕ — ЖЁСТКОЕ ПРАВИЛО

## 1. Запрещено навсегда
Любая **сгенерированная / процедурная музыка**: numpy/scipy-синтез, «drum&bass на скрипте»,
секвенсоры, любые файлы вида `music_catalog/*_174.ogg`, `music_dnb.py` и их производные.

Такие треки удалены из репозитория окончательно:
- `video_studio/music_catalog/dnb_neuro_174.ogg` — сгенерирован скриптом
- `video_studio/music_catalog/jungle_hoover_174.ogg` — сгенерирован скриптом
- `video_studio/v4/music_dnb.py` — сам генератор удалён

## 2. Разрешено
Только реальные скачанные мастера из `video_studio/music_downloaded/`:
`fvi-BeatOne.ogg`, `fvi-Arpent.ogg`, `fvi-Chronos.ogg`, `fvi-Favorite.ogg`,
`fvi-Fireworks.ogg`, `fvi-Goodnightmare.ogg`, `fvi-3amWestEnd.ogg`, `warfork_arpent.ogg`.

Путь к музыке обязан содержать `/music_downloaded/`, иначе сборка падает с ошибкой.

## 3. МУЗЫКА — ТОЛЬКО ДРАЙВОВАЯ (правило канала)
«В Окопе» — это военная среда, а не магазин на диване. Фон должен **толкать вперёд**:
бит слышно, низ давит, кровь в жилах стучит. Спокойные, «уютные», телешоу-подложки — запрещены.

**Обязательные критерии трека (все сразу):**
| Критерий | Порог |
|---|---|
| Темп | **≥ 120 BPM**, приоритет 140–180 (DnB / jungle / hardcore / neuro) |
| Суба-бас 35–100 Гц | **≥ 15 %** энергии спектра |
| Низ 100–300 Гц + суба | **≥ 30 %** энергии |
| Средний уровень | **≥ −18 dBFS** (не «шёпот») |
| Характер | прямой бит, качающий бас, без эмбиента, лаунжа, пианино-подложек |

**Микс — музыка должна бить, а не подметать:**
- В паузах голоса музыка **−11 … −13 LUFS**, то есть практически на уровне речи, иногда выше.
- Под голосом — дакинг **8–10 дБ** (sidechain 9:1, атака 5 мс, релиз 180 мс), чтобы слова читались.
- Мастер ролика: −14 LUFS, true peak −1,5 dB.
- Музыку «утопить» в −18 LUFS и ниже — запрещено (это и есть «магазин на диване»).

**Автопроверка:** `python3 video_studio/toolkit/music_check.py <файл.ogg>` — печатает BPM,
энергию низа и вердикт. Сборка звука обязана вызывать проверку; провал = остановка сборки.

## 4. Как выбирать
`fvi-BeatOne.ogg` — 162 BPM, низа больше всего: **дефолт для боевых и продающих Reels**.
Остальные — по вкусу, но только если проходят критерии из п.3. Эпичные/яркие треки
(`fvi-Fireworks`, `fvi-Goodnightmare`) годятся для торжественных выпусков, не для драйва.
