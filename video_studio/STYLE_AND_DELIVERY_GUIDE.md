# STYLE & DELIVERY GUIDE — спецвыпуски «В Окопе»

## Формат
- Художественная фронтовая документалка: полноэкранные атмосферные кадры + история. **Никаких витрин и продаж в лоб** (коротко упомянуть магазин — можно).
- 0:00 — **заставка** до начала речи. Приветствие: «серия спецвыпусков от магазина „В Окопе“».
- Каждая хитрость — **своя глава с заголовком**; интонация диктора явно отмечает переход.
- 30+ уникальных сцен, смена картинки каждые 3–5 с, snap-zoom, J-cut, пауза 0.5 с перед «раскрытием».
- Длина: короткие темы 2–3 мин; «большие» выпуски 6+ мин; вертикальный Reels — 1–20 мин (9:16, 1080×1920, 30 fps по умолчанию). Для сборки используйте `video_studio/reels/`; старый `video_studio/reel/reel.py` — фиксированный короткий промо-шаблон.

## Визуал
- Только современные ВС РФ: Цифра ЕМР, 6Б47, АК-74М / АК-12. Без WWI/WWII, без чужих шевронов, флагов, надписей.
- Цвет: `grade.look(img, "frontline")` (Kodak 2383 + teal/orange + зерно); ночь — `night_ops`; дрон/тепловизор — `thermal`.
- Текст: `typo.py` пресеты или AI-текст по рецепту из `toolkit/PROMPT_GUIDE.md`. Простой PIL-текст — запрещён.

## Звук
- Голос masculine voice-01, ускоренный, эмоциональный, чётко читается поверх музыки.
- `audio_fx.voice_chain()` — без «шёпот/крик» скачков; музыка — `carve()` + `duck()` (атака 5–10 мс, релиз 180–250 мс), **никаких «качелей»**.
- SFX из `toolkit/sfx` на каждой смене главы / раскрытии.
- Мастер: −14 LUFS, true peak −1,5 dB.

### МУЗЫКА — ТОЛЬКО ДРАЙВОВАЯ (обязательное правило)
Мы работаем в военной среде, а не в телевизоре с дивана. Музыка должна **толкать** ролик: бит слышно
с первых секунд, низ давит, темп гонит вперёд. Уютные, спокойные, «фоновые» подложки — **запрещены**.

- Жанр: живой DnB / jungle / neuro / hardcore / боевой электро-бит. Только реальные мастера из
  `video_studio/music_downloaded/` (никакого самодельного синта — см. `video_studio/MUSIC_POLICY.md`).
- Темп **≥ 120 BPM** (приоритет 140–180). Суба-бас 35–100 Гц **≥ 15 %** энергии спектра.
- Микс: в паузах голоса музыка **−11…−13 LUFS** (на уровне речи или громче), под речью дакинг **8–10 дБ**.
  Утопить музыку в −18 LUFS и ниже — брак, переделывать.
- Склейки кадра — по сетке бита (`beat_grid`), вспышки и удары текста — в долю.
- Автопроверка обязательна: `python3 video_studio/toolkit/music_check.py <трек>` → вердикт «ДРАЙВ»,
  иначе сборка останавливается.

## Сдача

тексты для Shorts / VK Клипы / Дзен / Telegram со ссылкой на полное видео на той же площадке.
Пользователь — новичок: простые шаги + прямые ссылки на скачивание.
