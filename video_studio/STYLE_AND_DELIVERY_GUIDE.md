# STYLE & DELIVERY GUIDE — спецвыпуски «В Окопе»

## Формат
- Художественная фронтовая документалка: полноэкранные атмосферные кадры + история. **Никаких витрин и продаж в лоб** (коротко упомянуть магазин — можно).
- 0:00 — **заставка** до начала речи. Приветствие: «серия спецвыпусков от магазина „В Окопе“».
- Каждая хитрость — **своя глава с заголовком**; интонация диктора явно отмечает переход.
- 30+ уникальных сцен, смена картинки каждые 3–5 с, snap-zoom, J-cut, пауза 0.5 с перед «раскрытием».
- Длина: короткие темы 2–3 мин; «большие» выпуски 6+ мин; рилс 30–45 с.

## Визуал
- Только современные ВС РФ: Цифра ЕМР, 6Б47, АК-74М / АК-12. Без WWI/WWII, без чужих шевронов, флагов, надписей.
- Цвет: `grade.look(img, "frontline")` (Kodak 2383 + teal/orange + зерно); ночь — `night_ops`; дрон/тепловизор — `thermal`.
- Текст: `typo.py` пресеты или AI-текст по рецепту из `toolkit/PROMPT_GUIDE.md`. Простой PIL-текст — запрещён.

## Звук
- Голос masculine voice-01, ускоренный, эмоциональный, **всегда громче музыки**.
- `audio_fx.voice_chain()` — без «шёпот/крик» скачков; музыка — `carve()` + мягкий `duck()` (атака 0.25 с, релиз 0.7 с), **никаких «качелей»**.
- Музыка: живая электроника DnB / jungle / hardcore (не самодельный синт). Склейки — по `beat_grid(music, bpm_hint=174)`.
- Мастер: −14 LUFS, true peak −1 dB.
- SFX из `toolkit/sfx` на каждой смене главы / раскрытии.

## Сдача
Всегда вместе с видео: **название, описание, теги, закреп, тайм-коды, обложка** (AI с текстом, проверенная орфография),
тексты для Shorts / VK Клипы / Дзен / Telegram со ссылкой на полное видео на той же площадке.
Пользователь — новичок: простые шаги + прямые ссылки на скачивание.

## Бренд «В Окопе» — логотип и заставка (обязательно для КАЖДОГО ролика)
- Логотип магазина: щит со стилизованным бойцом в каске «GOYDA», две звезды, ниже «В ОКОПЕ» и «магазин брони».
  Файлы (прозрачный фон, НЕ генерировать логотип нейросетью, НЕ перерисовывать):
  - `brand/logo.png` — белый, для тёмного фона (основной для видео);
  - `brand/logo_gray.png` — тёмно-серый, для светлого фона;
  - `brand/logo_black.png` — чёрный вариант.
- Заставка: `brand/ident.py` — лого влетает из глубины, вспышка+тряска, золотой блик, жёлтая плашка «ОКОПНАЯ СМЕКАЛКА».
  - `IDENT=short` (по умолчанию, ~2.8 с): «В Окопе». Окопная смекалка. — для рилсов;
  - `IDENT=full` (~5 с): «Магазин «В Окопе» представляет. Окопная смекалка.» — для длинных роликов.
  - Сборка: `python3 brand/ident.py prepend body.mp4 out.mp4 9x16` (или `16x9`).
- Магазин упоминается в заставке и в финале; в теле ролика тема начинается сразу (без «Магазин «В Окопе»!» поверх сюжета).
