## Картинка

- Палитра и шрифты канала: `#08090A` / `#FF7A2E` / `#2EC8BE`, RussoOne / DaysOne / JetBrainsMono.
- Склейка = реплика: 90 кадров, каждая смена картинки привязана к началу реплики (допуск ≤ 1 кадра).
- Динамика: зум-панч 45 мс на каждой склейке, микро-джампкат внутри кадров длиннее 4,4 с,
  бит-пульс 120 BPM, скан-линии, зерно (4-кадровый цикл), виньетка, HUD с прогрессом.

## Честные пометки (важно для модерации и для зрителя)

- Схемы интерфейса помечены «МАКЕТ · НЕ ЭКРАН ПРИБОРА» — это не съёмка реального прибора.
- Сгенерированные фоны помечены «ИЛЛЮСТРАЦИЯ».
- Реальные фото — только 4 присланных: комплект, антенны, часы (2 кадра). Они подписаны ««АЛДАН-12» · ФОТО».
- Кадров из исходного видео производителя нет — исходник не приложен к брифу.

## Что не проверено и требует человека

1. **Слух:** темп 1,125× и тембр `voice-28` — оценка только на прослушивании.
2. **Ударения:** «Алдан», «Эсент», «ченджлог», «оти-джи» — по словарю студии, подтверждение на слух за вами.
3. **Геометрия прибора:** расположение кнопок и разъёма — по описанию из видео, не по обмеру. Правится в `render_horz.py` за один проход.
4. **Фактбаза:** всё сказанное — из видео производителя и руководства; ТТХ, цен и «глушит» в ролике нет (проверка `check_facts.py` — 0 нарушений).
5. **Публикация:** без вашего «ок» никуда не выкладывается.

## Как пересобрать

```bash
cd video_studio/aldan12
python3 build_audio_h.py      # звук: 90 реплик + мастер
python3 build_release.py      # SRT, publish.txt, обложка 16:9
WORKERS=2 python3 render_horz_full.py   # видео 1920×1080
```

Для вертикали: `python3 reel_audio.py && python3 render_reel_full.py`.
