# Фактбаза «Алдан-12» — что можно утверждать

Источник: видео производителя (16:54) + руководство пользователя. Всё, чего нет в таблице, в кадре и в VO не звучит.
Проверка автоматическая: `python3 check_facts.py` (ищет запрещённые формулировки в shots.py).

## Разрешено

| Тема | Факт |
|---|---|
| Продукт | детекторы БпЛА «Алдан-12» и «Алдан-8» |
| Проблема из хука | два «Алдан-12» ведут себя по-разному: один видит цифровую видеосвязь Walksnail Ascent, второй молчит; причина — версия прошивки |
| Версия в примере | **1.6** |
| Откуда обновление | QR в руководстве/паспорте → Telegram-канал «Алдан-информация»: файлы прошивок, ченджлог, видео, ссылки. Нет QR — ссылки у продавца |
| Приложение | «Алдан», версия **1.2.6**, APK |
| Имена файлов | «Алдан-12» — начинается на **A2**, «Алдан-8» — на **A1** |
| Подготовка | собрать; антенны: малая по центру, две большие по краям; заряд — не меньше **одного деления**; включение — большая кнопка слева |
| Режим прошивки | зажать **нижнюю и верхнюю боковые кнопки** и включить (для «Алдан-12»; до этого шага порядок одинаковый) |
| Подключение | USB Type-C + OTG-переходник; разъём справа под заглушкой |
| OTG | включается в настройках телефона; на части телефонов функции нет |
| Помехи | авиарежим, отключить VPN, закрыть сторонние приложения |
| Диалог Android | «Выберите приложение для USB-устройства» → «Отмена» |
| Процесс | «Помощник обновления» → «Проверить версию ПО» → три точки → «Местная прошивка» → файл → «Обновление» → прогресс → прибор выключается |
| Проверка | включить → Настройки → «Версия» → сверить |
| Функция 1 | быстрые клавиши: громкость (нижняя/верхняя), экран (перечёркнутый глаз), блокировка (ключик), вибрация; дублируется в меню; «Настройки» → полный сброс сохраняет версию прошивки |
| Функция 2 | режим «Штурм», клавиша **3**: отключает обнаружение цифровых дронов (DJI, Autel) и цифровой радиосвязи, оставляет FPV, снижает чувствительность |
| Функция 3 | Настройки → LED → «Выкл» |
| Функция 4 | яркость до нуля, экран гаснет; настройка вибро/экрана/LED/звука |
| Функция 5 | обнаружение Walksnail Ascent, отображается на **5800 МГц**; тест сменой канала приёмника (Channel 5) |
| «Алдан-8» | те же функции, кроме быстрых клавиш — они в меню настроек |
| Часы | кнопка **5T**; широковещательный сигнал; число слушающих не ограничено; обновлять не нужно |
| Планы | выносная антенна на крышу здания/машины — «до конца года»; мониторинг новых систем управления и видеосвязи с добавлением в прошивку |

## Запрещено (проверяется скриптом)

дальность и радиус обнаружения · цена · вес · габариты · время работы и автономность ·
частоты, кроме 5800 МГц · «глушит / сбивает / перехватывает / подавляет» · «100 % обнаружения» ·
сертификация и лицензии · «официальное видео производителя» · любые ТТХ «по памяти».
