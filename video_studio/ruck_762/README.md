# Рюкзак тактический 7.62 (70 л) — два ролика 9:16

| Файл | Длина | Что внутри |
|---|---|---|
| `v_okope_ruck762_r1_9x16.mp4` | 30,65 с | «70 литров» — что за рюкзак, вес, габариты, узкий профиль, доступ, карманы, цвета |
| `v_okope_ruck762_r2_9x16.mp4` | 31,19 с | «Разбор по отсекам» — крышка, центральная молния, бока, низ, подвес |

Оба: 1080×1920, 30 fps, H.264 High + AAC 48 кГц, −14,0 LUFS, TP −1,5 dBFS.
Рядом — обложки `thumb_r1/r2_1080x1920.jpg`, превью, субтитры `R1.srt`/`R2.srt`,
тексты `publish.txt`.

## Как собрано

1. **Фото.** 8 кадров заказчика 1254×1254 — койот и хаки, вид сбоку, спереди, со спины,
   в дождевике. Рюкзак вырезан из студийного серого фона: `cutout.py` строит маску
   (фон = нейтральные светлые пиксели, объект = связная область от центра), отдельно
   сохраняет карту мягкой тени `assets/shadow/*.png`, а по краю силуэта перекрашивает
   серый ореол в цвет ближайшей ткани. Результат — `assets/cut/*.png`.
   Ничего не генерировалось: только эти 8 фото.
2. **Звук** (`build_audio.py`). 6 реплик для первого ролика и 4 для второго —
   voice-28, паузы подтянуты, цепочка `highpass 76 → presence 3,3 кГц +3,8 → компрессор 4,5:1
   → loudnorm −14,5`. Музыка — только `music_downloaded/`: `fvi-Chronos.ogg` (120 BPM) и
   `fvi-BeatOne.ogg` (162 BPM), обе прошли `music_check.py` с вердиктом «ДРАЙВ».
   Дакинг — sidechain 9:1, атака 5 мс, релиз 170 мс. Эффекты — CC0 из `toolkit/sfx`.
   Сценарии ставятся по фактической длине речи, а не по секундомеру: сцены привязаны
   к началу каждой реплики, финальная — к концу последней. Тайминги лежат в
   `timeline_r1.json` / `timeline_r2.json`, из них же собираются субтитры.
3. **Картинка** (`base.py`, `reel1.py`, `reel2.py`, `render.py`). Кадры рисуются в PIL:
   тёмная «студия», рюкзак с мягкой тенью и подсветкой, заголовки со слэм-анимацией и
   хроматикой, размерные линии, колауты, чипы, HUD «В ОКОПЕ» с прогресс-баром,
   скан-линии, зерно и виньетка. H.264 CRF 20, keyint 48.
4. **Документы** (`make_docs.py`, `check_facts.py`). Обложки и превью, субтитры,
   проверка: в текстах нет цен и несогласованных цифр.

## Что в кадре и в тексте

- Только факты из `facts.md` — они взяты из карточки заказчика.
- Габариты 40 × 20 × 75 см и вес 3,4 кг показаны плашками и размерными линиями,
  а не «на глаз».
- Закрывается всё карточкой «В ОКОПЕ» с контактами и пометкой «В НАЛИЧИИ».
- **Цены нет нигде** — ни в кадре, ни в озвучке, ни в описании (правило канала).

## Пересборка

```bash
python3 cutout.py        # вырезать рюкзак заново (нужен scipy)
python3 build_audio.py   # r1 и r2: голос + музыка + эффекты
python3 render.py r1 --full
python3 render.py r2 --full
python3 make_docs.py     # субтитры, обложки, превью
python3 check_facts.py
```

Проверка одного кадра без полного рендера: `python3 render.py r1 6.5 19.0`
(складывает jpg в `/tmp/rk`).
