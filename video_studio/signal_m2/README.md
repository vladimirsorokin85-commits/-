# «В ОКОПЕ» — РЭБ: «Сигнал-М2» и комплект станции

Два вертикальных Reels 9:16 (1080×1920, 30 fps) по материалам НПО «Киловатт» / «Мегаватт».
Голос `voice-28`, темп 1.22–1.25×, музыка `fvi-BeatOne.ogg` (duck 0.30), loudnorm I=-14.

| файл | длительность | размер | тема |
|---|---|---|---|
| `v_okope_signal_m2_reel_9x16.mp4` | 0:43.9 | 12.9 МБ | обнаружитель «Сигнал-М2», до 5000 м |
| `v_okope_kit_reel_9x16.mp4` | 0:44.0 | 14.3 МБ | что входит в комплект станции РЭБ |

## Сетка
«Сигнал-М2»: 2.60 титул · 11.40 ТТХ · 21.95 автоматика · 31.85 связки + заставка с 37.85
Комплект: 2.60 титул · 11.40 легковой автомобиль · 18.45 грузовая техника / стационар · 29.40 комплектация + заставка с 36.60

## Сборка
```bash
python3 build_audio.py     # master_signal_m2_9x16.mp3 + master_kit_9x16.mp3
python3 render_full.py     # оба mp4
```

Факты — из присланных паспортов изделий и материалов производителя. Цены не публикуются.
