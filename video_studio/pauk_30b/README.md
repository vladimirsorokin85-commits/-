# ПАУК 30Б — видеопакет «В Окопе»

Технический обзор ручного пехотного сеткомёта пистолетного типа «ПАУК 30Б / быстрозарядный».
Голос: `masculine` (voice-28), ускорение 1.18× + присутствие/компрессор.
Музыка: `fvi-BeatOne.ogg` (горизонталь) / `fvi-Arpent.ogg` (вертикаль), sidechain-дакинг.

## Технические особенности

- Непрерывное движение камеры (zoom + pan + shake) на каждой фоновой плите
- Кинетическая типографика: wipe-заголовки, наплывы, счётчики, прогресс-бары
- Анимированная схема перехвата: иконки, сетка, летящая сеть, шкала 10–40 м
- Анатомия картриджа с выносками и корпусом в разрезе
- Живая звуковая волна и VU-метр, построенные из реального аудио-мастера (`env.npy`)
- HUD-телеметрия: таймкод, прогресс, бегущая строка, световой скан, сканлайны, зерно
- Все плашки на плотной подложке `#0a0d14` — белого текста на светлом нет
- В вертикали таймкода нет (требование платформы)

## Скрипты

- `render_h.py` — движок горизонтали; `python3 render_h.py 12.5 40 80` рендерит кадры-проверки
- `render_full.py` — полный рендер горизонтали (rawvideo → ffmpeg → MP4)
- `render_reel.py` — движок вертикали
- `render_reel_full.py` — полный рендер вертикали
- `build_audio.py` / `build_reel_audio.py` — сборка аудио-мастеров с дакингом
