# Как отправлять каталог «В ОКОПЕ» × НПО «Киловатт»

Готовые файлы для отправки лежат в `kilowatt/dist/`:

| Файл | Что это | Кому |
|---|---|---|
| `Каталог_Киловатт_2026_В_ОКОПЕ.html` | Один самодостаточный файл: весь каталог внутри (стили, скрипты, шрифты, фото). Открывается в любом браузере, интернет не нужен. | Email (вложение), Telegram/WhatsApp, флешка, любой чат |
| `Каталог_Киловатт_2026_В_ОКОПЕ.pdf` | Печатный A4-каталог (ведомость, ТТХ, цены-ориентиры, контакты) | Email, Telegram, распечатка |

## Вариант 1 — письмо по e-mail

Тема:
```
Каталог «В ОКОПЕ» — станции РЭБ «Капюшон» НПО «Киловатт», 2026
```

Текст (короткий):
```
Здравствуйте!

Направляю каталог «В ОКОПЕ» — линейка станций РЭБ «Капюшон», «Штора», «Ребус-4»,
детекторов БПЛА и аксессуаров НПО «Киловатт» (Липецк). 43 позиции, ТТХ по паспортам,
цены поставщика — ориентиры, подтверждаются в КП.

Во вложении два файла:
- HTML-каталог (один файл, открывается в браузере, интернет не нужен);
- PDF-каталог (A4, можно распечатать).

Подберём контур под ваш объект: обнаружение, подавление, питание, документы.
Телефон: +7 (999) 136-71-42.

С уважением,
Владимир, «В ОКОПЕ»
```

Если у почтового сервиса лимит вложений меньше размера HTML — приложите только PDF либо
ссылку на облако (Яндекс.Диск/Google Drive). Обычные лимиты: Gmail 25 МБ, Mail.ru 25 МБ,
Яндекс 30 МБ — оба файла вместе укладываются.

## Вариант 2 — переписка (Telegram / WhatsApp / VK)

Короткое сообщение:
```
Каталог станций РЭБ «Капюшон» и линейки НПО «Киловатт» — 43 позиции, ТТХ по паспортам.
HTML открывается в браузере без интернета, PDF — для печати.
Подбор под объект и КП: +7 (999) 136-71-42
```
И приложить оба файла (HTML лучше отправлять «как файл», а не как документ предпросмотра).

## Вариант 3 — для клиента, который «не откроет файл»

Пришлите PDF + короткий текст выше. HTML — по запросу, если нужен интерактив
(фильтры, поиск, поле образца, заявка).

## Что важно в файлах

- HTML — автономный: все стили/скрипты/шрифты/фото внутри, внешних ссылок нет.
- В HTML нет переключателя «Вариант 1/2» и ссылок на PDF (это версия для отправки).
- PDF — новая печатная ведомость в стиле светлого каталога, 12–14 страниц A4.
- Цены в обоих файлах — цены поставщика как ориентиры, не публичная оферта.
- Правовой блок и дисклеймеры — в конце каталога (PDF) / в разделе «Документы» (HTML).

## Пересборка (для правок)

```powershell
$py = "C:\Users\TitanPC\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"

# 1) данные каталога (если менялись products.json/overrides.json)
& $py "D:\Проекты Дипсик\В ОКОПЕ\kilowatt\catalog\_tools\build_data.py"

# 2) single-file HTML для отправки
& $py "D:\Проекты Дипсик\В ОКОПЕ\kilowatt\catalog\_tools\build_singlefile.py"

# 3) печатный HTML + PDF
& $py "D:\Проекты Дипсик\В ОКОПЕ\kilowatt\print\build_print_light.py"   # если скрипт есть
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\Проекты Дипсик\В ОКОПЕ\kilowatt\catalog\_tools\build_pdf.ps1" `
  -Html "D:\Проекты Дипсик\В ОКОПЕ\kilowatt\print\print-light.html" `
  -Out  "D:\Проекты Дипсик\В ОКОПЕ\kilowatt\dist\Каталог_Киловатт_2026_В_ОКОПЕ.pdf"
```
