Правила интеграции:

1. Картинки кладутся в `catalog/assets/img/art/` с теми же именами.
2. В изображениях **нет текста** — все заголовки/цифры/цены живут в HTML/CSS,
   поэтому обложка собирается как композиция: арт-подложка + типографика.
3. При выборе концепта берём только один набор A/B/C; остальные остаются в
   `design/` как альтернативы, в каталог не попадают.
4. Для PDF те же файлы используются как фоны A4-страниц (кроп по `background-size: cover`).
