# Промпт для Arena (скопировать целиком в новую Arena-сессию с GitHub)

```
Репозиторий: vladimirsorokin85-commits/-
Задача: арт для самостоятельного каталога «В ОКОПЕ» (продукция НПО «Киловатт»).

1. Прочитай файл arena/mail/out/0002-lead-kilowatt-art.md целиком — это задание.
2. Сгенерируй РОВНО 10 изображений по спецификации из задания, положи в
   kilowatt/arena-art/ с точными именами файлов.
3. Собери kilowatt/arena-art/MANIFEST.md: файл → промпт → что получилось.
4. Напиши отчёт arena/mail/in/0002-arena.md (что сделано, что не вышло, ссылка на PR).
5. Запушь ветку arena/<id>-repo и открой ОДИН PR в main. Другие файлы не трогай,
   в main напрямую не пушить, чужие ветки не перезаписывать.

Критично: НИ ОДНОЙ буквы/цифры/логотипа на изображениях (текст наложим в HTML).
Без нейрослопа: чёрное с золотом, градиенты, неон, стекломорфизм, 3D-глянец,
сток-фото — запрещены. Только печатная графика: шелкография/ризограф,
2–3 цвета, зерно бумаги, лёгкая неприводка, честная пустота под типографику.
Проверь размеры и что файлы открываются. Если картинка вышла «стоковой» —
переделай один раз с усилением flat screenprint / paper grain / no 3D.
```

## Что дальше делает владелец

1. Вставить промпт в новую Arena-сессию с репозиторием (старые сессии не видят свежий `main`).
2. Дождаться PR от Arena и сказать в чат «ARENA готово» — чат заберёт картинки,
   вставит их в каталог и покажет три обложки на выбор.

## Файлы

- `ARENA_BRIEF.md` — полное задание (лежит и в репозитории: `arena/mail/out/0002-lead-kilowatt-art.md`).
- `SLOTS.md` — куда какая картинка встанет в каталоге.
