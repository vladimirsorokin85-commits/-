## 4. Что нельзя писать

- «Глушит всё», «100% защита», «гарантированно сбивает» — нет.
- «Официальный дилер», «официальный представитель» — статус не подтверждён.
- Пожизненная гарантия — по паспортам **12 месяцев**.
- «Включи и защищай» для гражданских объектов: применение РЭБ регулируется
  (КоАП 13.3/13.4, 126-ФЗ, ПП 1800/1331, ГКРЧ); в материалах — честный дисклеймер,
  продаём подбор + обнаружение + документы + сервис.
- ТТХ по дилерским постам (например, «Штора до 2 км FPV / 5 км Mavic») — НЕ использовать,
  канон по паспорту: до 1000 м.

## 5. Обложка / визуальный язык

- В работе два варианта каталога: **1 «Тёмное поле»** (олива/графит + кислотный лайм)
  и **2 «Зона защиты»** (тёплая бумага/графит + оксидный акцент, инженерная схема зоны).
- Владелец ещё выбирает. До решения для постеров безопасно использовать **язык
  варианта 1** (тёмное поле, плакатность) — он ближе к рекламной подаче.
- Готовые токены: `kilowatt/design/tokens.css`; превью: `kilowatt/preview/`.
