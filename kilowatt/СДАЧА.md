## 1.2. Редизайн светлого варианта — 07.11.2026

Владелец: «верхушка (hero с контуром „РЭБ“) — самая ништяк, её не трогать; всё остальное
переработать, карточки — современнее». Сделано командой из 5 агентов с микрозадачами:

| Микрозадача | Агент | Результат |
|---|---|---|
| 3 концепта лэйаута ниже hero | layout-designer | «Ведомость», «Разворот», «Полка» — `redesign/layout/` |
| 3 системы карточек | cards-designer | «Ведомость» (рекомендация), «Стенд», «Рельсы» — `redesign/cards/` |
| Моушн и переходы | motion-engineer | `redesign/motion/motion.css|js` + demo + README |
| Корректура типографики | copy-editor | 678 правок, `redesign/copy/edits.json` → вшиты в конвейер |
| Сборка нового variant-2 + QA-стенд | frontend-builder, motion-engineer | `variant-2.html`, `light.css`, `app-light.js`, `catalog/_tools/qa/qa_check.py` |

Что изменилось в светлом варианте:
- **Hero — 1-в-1 как был** (сверено с эталоном), шапка адаптирована под 1024/820/390.
- **Каталог — «ведомость»:** строки `№ 01/43 · фото · имя · бейджи · 300–5900 МГц · до 240 Вт · 50–200 м · цена · «Подробнее →»`; липкое «поле образца» справа меняется по hover/focus; категории-полки со счётчиками; sticky-тулбар; фильтры (6 категорий + «Вне сайта»), поиск, сортировка, «показано N из 43».
- **Флагманы — «стенд»:** 3 асимметричные плитки (7×2 + 2×5 колонок), на мобиле — в колонку.
- **Секции 01–07** — редакционный ритм: выносные номера, крупные Oswald-заголовки, волосяные линии, без коробок; сравнение, степпер поставки, документы, заявка с QR-контактом.
- **Моушн:** reveal секций/строк, hover/focus, sticky, модалка, корзина, мобильное меню (drawer), ScrollSpy, view transitions вариантов; `prefers-reduced-motion` — полное отключение.
- **Типографика:** «ёлочки»/„лапки“, среднее тире в диапазонах, U+2212 в температурах, NBSP в единицах/№/₽/телефоне — 0 нарушений в QA; правки вшиты в `build_data.py`/`build_print.py`, не теряются при пересборке.
- **Печать:** PDF остались в прежней A4-вёрстке, но с выверенной типографикой (13 стр. каждый).

**QA финального variant-2 (автотест, 2 прогона подряд):** PASS 34 / FAIL 0 / WARN 0;
overflows 1440/1024/820/390 — 0; JS-ошибок 0; битых фото/ссылок 0; модалка, корзина,

**QA-свип обоих вариантов (после финальных правок, 2 прогона):** `variant-2.html` — PASS 34/34,

## 4. Главные факты и риски (проверено)

- **«Ребус-4», «Штора» К-12/700, «Штора-М» К-8/600 по паспорту изготовлены ООО «НПО «МЕГАВАТТ»»**,
  К-12М — ООО «НПО «КИЛОВАТТ»». В договоре указывать по паспорту.
- **Цены — ориентиры поставщика за 2024–2026** (К-12М 800 000 ₽, Штора К-12/700 1 900 000 ₽,
  Ребус-4 — только «по запросу»). Не оферта, подтверждать в КП.
- **Правовой риск:** применение РЭБ без специального права — КоАП 13.3/13.4 (юрлицам 30–90 тыс. ₽
  + конфискация); с 01.03.2027 ПП № 1331 — регистрация только для уполномоченных. Для обычных
  ООО (склад, завод, АЗС, ЧОП) прямого основания нет — в каталоге не обещаем «включи и защищай»,
  только подбор + обнаружение + документы + честный дисклеймер.
- Никаких выдуманных характеристик: всё из паспортов/сайта/базы; расхождения зафиксированы.
