# _render — пайплайн «СУПЕРЦЕНЫ» (карусель v5, печатный плакат)

Рендер 81 PNG (20 позиций × 4 страницы + hero) из `superceny/03_HTML/` в
`superceny/05_ГОТОВОЕ/`, контактные листы «4 подряд», галерея-карусель и чек-лист.
База — пайплайн `banners/_render` (Chrome CDP, детектор наложений/переполнений).
Дизайн v5 «СОРВАННЫЙ ЦЕННИК»: бумага/тушь/красная краска, duotone-ассеты
`02_ДИЗАЙН/img/print/*_duo.png`.

## Быстрый старт

```powershell
# полный прогон: ассеты → рендер (батчи, prune) → контакт-листы → 540/390 → галерея → чек-лист
powershell -NoProfile -ExecutionPolicy Bypass -File superceny\_render\run_all.ps1

# проверка ассетов (битые img, прозрачность duotone)
& $py superceny\_render\check_assets.py

# проверка комплектности HTML до рендера
& $py superceny\_render\preflight.py

# только новые/изменившиеся HTML (докатка), батч 40
& $py superceny\_render\render_cards.py --all --only-new --batch-size 40

# одна позиция / один слайд
& $py superceny\_render\render_cards.py --folder 03_К-8М
& $py superceny\_render\render_cards.py "superceny\03_HTML\03_К-8М\01_ЛИСТАЙ.html"

# контакт-листы «4 подряд» отдельно
& $py superceny\_render\make_carousels.py
```

Python с Pillow: `C:\Users\TitanPC\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe`

## Скрипты

| Файл | Что делает |
|---|---|
| `superlib.py` | пути, раскладка HTML→PNG (папки позиций, hero), meta из `01_ДАННЫЕ/positions.json`, константы 20/80/81, имена слайдов |
| `check_assets.py` | проверка перед рендером: битые ссылки на img/CSS-ассеты; прозрачность duotone (`*_duo.png` — RGBA + реальные прозрачные пиксели) |
| `preflight.py` | проверка «80+1 HTML готовы»: папки, слайды 01–04, hero, сверка папок с positions.json |
| `render_cards.py` | CDP-рендер 1080×1350 батчами: размеры, битые фото, переполнение документа, текст за кадром, наложения; `--prune` убирает PNG старой версии; ghost/aria-hidden декор не считается текстом за кадром; JSON-отчёт |
| `make_carousels.py` | **20 контактных листов** «4 слайда подряд» → `04_ПРОВЕРКА/карусели/<позиция>.png` (2700 px, печатная палитра, подписи, стрелки, перфорация) |
| `make_readability.py` | уменьшенные копии 540 и 390 px для QA → `_render/_qa/readability/{540,390}/` |
| `gallery.py` | `05_ГОТОВОЕ/gallery/index.html` — галерея-карусель v5 в светлой бумаге: 4 слайда в ряд + стрелки, hero, офлайн |
| `check_files.py` | приёмка: 81 PNG, структура папок, размеры/веса/время рендера, 20 контакт-листов → `ЧЕК_ЛИСТ_ФАЙЛОВ.md` |
| `run_all.ps1` | последовательный прогон 6 шагов (батч 40, с `--prune`) |

## Раскладка и имена

`03_HTML/<NN_Название>/01_ЛИСТАЙ.html` → `05_ГОТОВОЕ/<NN_Название>/01_ЛИСТАЙ.png`
(и так же `02_ЦИФРЫ`, `03_СЦЕНАРИИ`, `04_CTA`).
`03_HTML/00_СУПЕРЦЕНЫ.html` → `05_ГОТОВОЕ/00_СУПЕРЦЕНЫ.png` (hero).
Имя PNG всегда каноническое по номеру слайда, даже если HTML назван иначе.
Папки — из `positions.json` (01–20, как у заказчика).
Контактные листы: `04_ПРОВЕРКА/карусели/<папка>.png` — полоса 4 слайда подряд.

## Детектор

FAIL: битые `<img>`, переполнение документа (контент больше 1080×1350 — была бы обрезка),
текст за границей кадра (кроме декора `aria-hidden`/ghost), ошибки шрифтов, неверный размер/вес PNG.
WARN: `overflow:hidden` с обрезанным содержимым (обычно намеренный bleed/кроп фото),
наложения текстовых блоков (>35% площади), шрифты не в состоянии `loaded`.

Отчёт: `_render/_qa/render_report.json` (по каждому файлу, с `rendered_at`).
Если слайд сломан — сообщение Lead/designer-a с путём HTML и PNG; **HTML не правим**.

```powershell
& $py _render\render_cards.py --all --batch-size 6
& $py _render\make_carousels.py; & $py _render\gallery.py; & $py _render\check_files.py --partial
```

## Особенности больших прогонов

- Рендер идёт батчами (`--batch-size`, по умолчанию 40): каждые N слайдов Chrome
  перезапускается — стабильность, прогресс печатается.
- `--only-new` докатывает только изменившиеся HTML (mtime HTML > mtime PNG).
- `--prune` удаляет из `05_ГОТОВОЕ` PNG/папки, которых нет в текущем составе
  (при смене версии/имён слайдов).
- Позиции 01 «Муха К-8» и 08 «Изделие 135 Багажный бокс» — без данных каталога,
  слайды со заглушкой «фото уточняется»; это норма, не дефект.
