## Цены — как добавить

Сейчас все цены = «Прайс по запросу» (`price_value: null`). Когда придут конкретные цены:
1. В `01_ДАННЫЕ\positions.json` заполнить `price_value` (например `"550000"`) у нужных позиций.
2. Запустить `python 02_ДИЗАЙН\generator.py --clean` — перегенерация 81 HTML с ценой.
3. Запустить `_render\run_all.ps1` — перерендер PNG, галереи, чек-листа.
Всё, цена появится в карточках 01 и 04 и в hero (если добавить в hero-данные).
