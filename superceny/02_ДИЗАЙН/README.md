# «СУПЕРЦЕНЫ НА НПО „КИЛОВАТТ“» — 4 карточки на позицию + hero

Пакет: **20 позиций прайса** × 4 карточки (1080×1350) + общая `00_СУПЕРЦЕНЫ`.
Дизайн-система и генератор — здесь, в `superceny\02_ДИЗАЙН\`.

## Что где лежит

```
superceny\01_ДАННЫЕ\positions.json     данные позиций (analyst) — единственный источник текстов
superceny\02_ДИЗАЙН\tokens.css         брендовые токены/темы (field — тёмная, quiet — светлая)
superceny\02_ДИЗАЙН\super.css          вёрстка серии: card-01…04 + hero + заголовок/футер
superceny\02_ДИЗАЙН\generator.py       генератор: positions.json → 81 HTML
superceny\02_ДИЗАЙН\fonts\             Sofia Sans Extra Condensed / Oswald / Tektur / Unbounded
superceny\02_ДИЗАЙН\img\               фото товаров от designer-b: <kw-id>_main.png (RGBA, прозрачный фон)
superceny\02_ДИЗАЙН\img\brand\         логотипы «В ОКОПЕ» / НПО «Киловатт»
superceny\03_HTML\<folder>\            4 HTML на позицию + 00_СУПЕРЦЕНЫ.html в корне
superceny\05_ГОТОВОЕ\                  PNG-сдача (renderer): 20 папок × 4 + hero + gallery
```

## Компоновки серии

| Файл | Тема | Что на карточке |
|---|---|---|
| `01_СУПЕРЦЕНА.html` | field (тёмная) | бейдж **СУПЕРЦЕНА**, хук, категория, крупное название, рекламная строка, большое фото, слоган **ЛУЧШЕ НЕ НАЙДЁТЕ**, прайс-зона, CTA |
| `02_ХАРАКТЕРИСТИКИ.html` | quiet (светлая) | фото-полоса, таблица 6–8 ТТХ из паспорта в 2 колонки, изготовитель/комплект/наличие, примечание |
| `03_ПРИМЕНЕНИЕ.html` | field (тёмная) | хук + название, 4 коротких `tasks` (кому/для чего), полоса ключевых ТТХ, крупное фото, слоган |
| `04_СУПЕР-ПРЕДЛОЖЕНИЕ.html` | quiet (светлая) | бейдж **СУПЕРЦЕНА**, 4 преимущества из `benefits`, комплект, фото, прайс-зона, CTA |
| `00_СУПЕРЦЕНЫ.html` | field (тёмная) | hero: слоган, коллаж 8 товаров, «20 позиций прайса», условия, CTA |

Единые элементы серии: шапка (логотип + «НПО „Киловатт“ производитель» + NN/тип), футер
(TG `@vokope_ru`, `+7 (999) 136-71-42`, «Прайс по запросу · Доставка по РФ · Самовывоз в Москве»),
юрстрока, слоган. Один акцент на карточку, без градиентов/теней/неона.

## Перегенерация

```powershell
# все 20 позиций + hero (очищает 03_HTML от старых папок)
& $py "D:\Проекты Дипсик\В ОКОПЕ\superceny\02_ДИЗАЙН\generator.py" --clean

# только часть позиций (hero не перегенерируется)
& $py "...\generator.py" --only kw-05,kw-19

# другой JSON
& $py "...\generator.py" --data "...\positions.json" --out "...\03_HTML"
```
`$py` — python из рантайма DSH (или любой python 3.10+). Генератор не требует зависимостей.

## Цены

Сейчас везде **«Прайс по запросу»**. В `positions.json`:
- `price_value: null` → на карточках выводится `price_note` (по умолчанию «Прайс по запросу»);
- `price_value: 12345` → подставляется число (`12 345 ₽`).

Чтобы поставить цены: заполнить `price_value` у нужных позиций и один раз перегенерировать
`--clean` (карточки 01 и 04 подхватят цену автоматически). Цены не выдумывать —
только из прайса заказчика.

## Данные и правила

- Тексты — только из `positions.json`: `name`, `hook`, `super_line`, `tasks`, `benefits`,
  `specs`, `price_note`, `manufacturer`, `availability`. Ничего не додумываем.
- Папки и порядок — строго из `positions.folder` (`01_Муха-К-8` … `20_РЭБ-тестер`).
- Позиции без данных (01 «Муха К-8», 08 «Изделие 135»): плашка «ФОТО УТОЧНЯЕТСЯ /
  НОВАЯ ПОЗИЦИЯ · ПОД ЗАКАЗ», блок «ХАРАКТЕРИСТИКИ ПО ЗАПРОСУ», без выдуманных цифр.
- Запрещено: конкретные цены (до решения заказчика), «официальный дилер», «100% защита»,
  «спасёт жизнь», «дрон не пролети», «единственный», «инновационный», военная риторика,
  слово «архив» для новых позиций.

## Фото

Генератор ищет `02_ДИЗАЙН\img\<id>_main.png`; если файла нет — fallback на исходный JPG
`kilowatt\data\photos\<slug>\01.jpg` (только для предпросмотра). После прихода новых
вырезок достаточно перегенерировать HTML.
