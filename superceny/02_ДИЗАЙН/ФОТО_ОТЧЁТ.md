## 3. Как обработано (воспроизводимо)

1. **Выбор кадра:** официальное главное фото из галереи позиции (для ВИП/бокса/ИП — кадр,
   где видно само изделие); смотрел контактные листы всех кандидатов каждой позиции.
2. **Фон → прозрачность:** flood fill от краёв кадра по near-white (threshold 40) → alpha 0;
   для тёмных изделий дополнительно вычищены замкнутые белые полости (отверстия, скобы);
   эрозия alpha 1 px + GaussianBlur 0.6 — убран белый ореол, край мягкий.
3. **Кроп:** по bbox изделия + 2 px запаса (без пустого верха/полей — как просил Lead).
4. **Масштаб:** LANCZOS до ширины 1800 px (пейзаж) / 1600 px (портрет, h > 1.25·w),
   лёгкий UnsharpMask после апскейла. PNG RGBA, optimize.
5. **Имя:** `<kw-id>_main.png` / `<kw-id>_alt.png` — ровно как ждёт генератор designer-a
   (`../../02_ДИЗАЙН/img/<id>_main.png`).

## 8. Печатные duotone-ассеты v5 «СОРВАННЫЙ ЦЕННИК» (12.11.2026)

По брифу §11 и анти-слоп-правилам заказчика для печатного плаката сделаны ассеты
в две краски: **красная `#E23B2E` + чёрная тушь `#17150F`**, полутон, мисрегистрация,
зерно, прозрачный фон — вместо обычных cutout. Папка: `superceny\02_ДИЗАЙН\img\print\`.

### 8.1. Фото (18 позиций каталога)

| Файл | Что | Размер | Кол-во |
|---|---|---|---|
| `<id>_duo.png` | duotone-полутон основного кадра (`_main`) | по исходнику (1600–1800 px) | 18 |
| `<id>_duo_zoom.png` | duotone-полутон крупного кадра (`_zoom`) | по исходнику | 18 |

**Техника:**
1. Grayscale + нормализация контраста по 3–97 перцентилям внутри контура товара.
2. **Две краски, каждая — свой поворот сетки:** красная 75°, чёрная 15° (классические углы,
   чтобы не было муара от наложения).
3. **Полутон:** AM-растр, круглые точки, pitch = ширина/180 (≈ **50 lpi** при полной ширине
   карточки 1080 px = 3,6″ @300 dpi), антиалиас по краю точки 1 px, при покрытии ≥97% — заливка.
4. **Роль красок:** красная доминирует в средних тонах и светах (0,10 + 0,90·(1−L)^0,70),
   чёрная — тени (1−L)^1,30; в светах больше бумаги, тени почти чёрные.
5. **Мисрегистрация:** красный слой сдвинут на **+3 / −1 px** (2–3 px), чёрный — по месту;
   alpha по контуру товара (красный — со своим сдвигом).
6. **Зерно:** мелкий шум ±2,5% по тону + ±3% по покрытию красок.
7. **Прозрачный фон**, без белых ореолов (alpha из контура, край вырезан по alpha main).
8. **Оптимизация веса:** PNG в палитре 128 цветов (визуально идентично RGBA, вес −75%);
   при необходимости отдам полные RGBA-версии.

**Проверка:** 1080 px — полутон читается, мисрегистрация видна на 1:1; 390 px — товар
узнаваем, «ряби»/муара нет; на бумаге #F1E8D6 выглядит как 2-красочная печать.
