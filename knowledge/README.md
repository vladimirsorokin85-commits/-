# База знаний «В ОКОПЕ» — как вести

Это наш «мозг по грамотности»: сюда пишем всё, что нужно знать, чтобы посты и подборы
были профессиональными — факты, классы защиты, бренды, разъёмы, медицину, уроки на ошибках.

## Файлы

| Файл | Что это |
|---|---|
| `db.json` | сама база: записи с источником и датой |
| `db.py` | инструмент: добавить, найти, показать темы |
| `tactical.md` | читаемая выжимка по бронезащите (для быстрого «освежить в голове») |

## Команды

```bash
# найти по слову
python3 knowledge/db.py find бр5

# показать всё по теме
python3 knowledge/db.py topic защита

# добавить запись
python3 knowledge/db.py add --topic защита --title "Бр5 — что держит" \
  --fact "Бр5: СВД 7,62×54, пуля с термоупрочнённым сердечником, 10 м" \
  --source "ГОСТ 34286-2017" --tag броня --tag классы

# что вообще есть в базе
python3 knowledge/db.py topics
```

## Правила ведения (важно)

1. **Без источника — не запись.** Каждый факт идёт с источником: ГОСТ, сайт производителя,
   официальный дистрибьютор, форум (с пометкой «мнение»). Наши догадки в базу не попадают.
2. **Уроки с ошибок — тоже сюда.** Если владелец поправил («штурмовик на базовом плитнике —
   засмеют»), это запись с тегом `урок`: чтобы больше так не делать.
3. **Сначала база, потом пост.** Собирая комплект, проверяем по базе: тот ли уровень защиты,
   сходятся ли разъёмы, не противоречит ли комплект задаче.
4. **Сомневаешься — гугли и записывай**, а не выдумывай.
